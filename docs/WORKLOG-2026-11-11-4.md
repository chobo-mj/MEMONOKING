# 작업 기록 — 2026-11-11 (4차)

이름을 OmniMemoJang으로 바꾸고, 빠른 메모·첫 화면·메뉴 숨기기·캘린더 설정을 넣었다. 최종판을 위한 문서 [ARCHITECTURE.md](ARCHITECTURE.md)와 [SPEC.md](SPEC.md)도 썼다.

## 반영한 요청사항

| 항목 | 내용 |
|---|---|
| 빠른 메모 | 메뉴창의 "빠른 메모" 버튼과 빠른 메모 단축키는 새 스티커 메모를 연다. 예전 빠른 메모 대화상자와 그 코드는 지웠다. |
| 첫 화면 | 설정 › 일반 › 첫 화면에서 시작 메뉴를 고른다. 숨긴 메뉴는 고를 수 없다. |
| 메뉴 숨기기 | 설정 › 일반 › 메뉴 숨기기. 내 작업실을 뺀 모든 메뉴를 숨길 수 있다. 보던 메뉴를 숨기면 내 작업실로 돌아간다. |
| 캘린더 설정 | 설정 › 캘린더. 테마(기본·종이·세이지·나이트), 캘린더 안 메모 글자 크기(9–18pt), 완료 일정 숨기기, 완료 일정 취소선, 보기 단위(한 달·1주·2주). |
| 근무자 보기 | 캘린더 머리줄의 "작성일" 옆에 버튼만 넣었다. 동작은 후속 구현이다. |
| 이름 변경 | OmniMemoJang으로 바꿨다. 아래 범위에 모두 적용된다. |
| 배너 | 메뉴창 상단에 주황 그라데이션 카드를 그린다. 워드마크는 "Omni·Memo·Jang" 색 구분이고 문구는 "모든 메모와 일정을 한곳에"다. 모서리 장식이 글자와 겹쳐 위치를 고쳤다. |
| 설정 저장 | 위 설정(첫 화면, 숨긴 메뉴, 캘린더 옵션)은 `%APPDATA%\OmniMemoJang\settings.txt`에 저장되어 재시작 후에도 남는다. |
| 문서 | `docs/ARCHITECTURE.md`(코드 구조와 최종판에 더 붙일 부분), `docs/SPEC.md`(기능 명세와 구현 상태, 완성 기준) |

이름 변경이 적용된 곳:

- 실행 파일 `omnimemojang.exe`
- 창 제목
- 설치 스크립트 `packaging/OmniMemoJang.iss`
- GitHub Actions 빌드·배포
- 테스트 시계 환경 변수 `OMNIMEMOJANG_TEST_NOW`

## PC에서 확인한 항목

- 새 이름의 실행 파일과 창 제목, 메뉴창 배너
- "빠른 메모" 버튼 → 새 스티커 메모가 열림
- 첫 화면을 캘린더로, 편의기능을 숨김으로 설정 → 재시작하면 캘린더 화면으로 열리고 편의기능 메뉴가 보이지 않음. 확인 후 설정을 기본값으로 되돌렸다.
- 캘린더 설정 화면, 2주 보기, 근무자 보기 버튼 (로컬 화면)
