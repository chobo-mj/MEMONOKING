# 작업 기록 — 2026-11-12

근무자 보기를 뺀 남은 기능을 마무리했다. 메모·위키·설정 저장, 알람, 자동 실행, 휴지통 정리, 자동 잠금, 백업·복원을 넣었고, 나만의 위키에 사용법 탭을 만들었다.

## 반영한 내용

| 항목 | 내용 |
|---|---|
| 데이터 저장 | `storage.rs` 신설. 메모, 프로젝트, 연결, 위키 탭·폴더, 전체메모 폴더, 휴지통, 설정을 `%APPDATA%\OmniMemoJang\data\data.json`에 자동 저장한다(2초마다 바뀐 경우만, 종료 시에도). 그림은 `images\<해시>.png`에 한 번만 쓴다. 쓰기는 임시 파일 후 이름 바꾸기 방식이고, 읽을 수 없는 파일은 `data.broken-*.json`으로 옮겨 보존한다. |
| 비밀번호 | 잠금 메모 비밀번호는 솔트를 붙인 SHA-256 해시로만 보관한다. 비밀번호가 있는 메모는 시작할 때 잠겨 있다. |
| 알람 | `alarm.rs` 신설. 시각이 되면 Windows 알림 소리와 함께 오른쪽 아래에 알림 창이 뜬다(열기·5분 뒤·확인·모두 확인). 꺼져 있던 동안 지난 알람은 "놓친 알람"으로 보여 준다. 팝업을 끄면 메인 창 알림으로 대신한다. |
| 자동 실행 | 설정 › 일반 › Windows 시작 시 자동 실행이 현재 사용자 Run 키(`OmniMemoJang`)를 쓰고 지운다. |
| 작업표시줄 | 끄면 새로 여는 스티커 창이 작업표시줄에 나타나지 않는다. |
| 휴지통 보관 기간 | 7·30·90·365일이 지난 휴지통 메모를 프로그램 시작 때 완전히 지운다. |
| 자동 잠금 | 잠금 메모를 연 뒤 1·5·15분이 지나면 다시 잠근다. |
| 백업 / 복원 | "지금 백업"은 `backups\<날짜시각>\`에 저장한다. "백업에서 복원"은 복원 전에 현재 데이터를 한 번 더 백업한다. |
| 사용법 | 나만의 위키의 ‘사용법’ 탭에 메뉴별 메모 10개를 화면 이미지와 함께 넣었다. 이미지는 `assets/guide/*.jpg`를 실행 파일에 포함했다. |
| 첫 실행 | 첫 실행 때만 사용법을 연다. 다음부터는 내 작업실(설정의 첫 화면)로 시작한다. 사용법 메모는 할 일 목록과 캘린더에 섞이지 않으며, 설정 › 정보의 "사용법 보기"로 다시 연다. |
| 새 작업 공간 | 예시 메모 없이 사용법만 있는 상태로 시작한다. |
| 문서 | SPEC.md(상태 갱신, C-7 추가), ARCHITECTURE.md(저장 계층·알람·남은 부분) |

## 확인

- **테스트:** Windows `cargo test --release` 106개 통과, `cargo clippy --all-targets` 경고 없음. Linux에서 Windows 대상 clippy도 통과했다. 새 테스트 3개는 아래와 같다.
  - 저장·복원 왕복(그림·비밀번호 해시·기간 일정·알람 포함)
  - 알람 대상 판정
  - 사용법 설치
- **로컬 화면:**
  - 첫 실행 → 사용법 탭이 열리고, 재시작 → 내 작업실이 열림
  - 알람 2개(놓친 알람)가 오른쪽 아래에 뜸 → "확인"한 알람만 지워져 저장됨
- **PC:**
  - 첫 실행에 사용법 탭이 열리고 `data.json`과 그림 9개가 저장됨
  - 재시작하면 내 작업실이 열림

## 참고

- 원격 복사 도구는 이진 파일(JPG)을 깨뜨려서, base64로 보낸 뒤 PC에서 복원했다. `git write-tree` 해시로 PC와 저장소가 같음을 확인했다.
- 자동 실행 토글은 레지스트리를 바꾸므로 PC에서 실제로 켜 보지는 않았다. 코드와 Windows 빌드만 확인했다.
