# 작업 기록 — 설정창 크기를 텍스트크기에 맞춰 조정 (2026-11-12)

## 배경

백로그 49번: 설정창(설정 대화상자) 크기를 텍스트 크기에 맞춰 조정해, 글자 크기를 키웠을 때 스크롤 없이 보이게 해 달라는 요청.

## 원인

설정 대화상자는 `src/main.rs::global_dialogs()`에서 고정 크기 `[860., 620.]`로 열립니다. 그런데 이 대화상자는 앱 전체와 스타일(글꼴·글자 크기)을 공유하므로, 설정 > 메인창 탭의 "글꼴 크기"(8~16pt, 기본 10pt)를 키우면 설정창 안의 모든 행도 함께 커져서, 고정된 620px 높이 안에서 기존에 있던 세로 스크롤 영역이 더 일찍, 더 자주 발동하게 됩니다.

## 수정

`global_dialogs()`에서 설정창의 높이를 `font_size / 10`의 비율(1.0~1.6배로 제한)만큼 늘리도록 했습니다. 기본 글자 크기(10pt)에서는 기존과 동일한 620px이고, 최대 글자 크기(16pt)에서는 약 992px까지 늘어납니다. 너비는 내용이 어차피 내부적으로 320~600px로 줄바꿈되므로 그대로 두었습니다.

## 검증

- Linux: `cargo check`, `cargo clippy --all-targets` 경고 없음, `cargo fmt` 통과. `cargo test` 113/114 (환경 전용 글꼴 실패 1건, 무관).
- Windows PC: `cargo build`, `cargo test` 114/114 통과.
- 실제 창 크기 변화(글자 크기를 바꿔가며 스크롤이 줄어드는지)는 자동화된 조작으로 세세히 확인하지 않았습니다 — 빌드/테스트 통과로 검증을 갈음했습니다. 체감 결과가 다르면(여전히 스크롤이 필요하거나 창이 화면보다 커지면) 알려주시면 배율을 조정하겠습니다.
