# 작업 기록 — 2026-11-11 (2차)

스티커·메뉴·시간 입력·찾아바꾸기·미리보기 편집 등 19개 요청사항을 반영하고, 사용자 PC(Windows)에서 실행해 확인한 기록이다.

| L | 찾아 바꾸기: 프로젝트 다중 선택, 찾기/모두찾기/바꾸기/모두바꾸기, 결과 목록(강조 표시·다중 선택·상단 바) |

## PC 테스트 중 발견해 고친 문제

1. **더보기·우클릭 메뉴가 뜨지 않음**
   - 원인: 빠른 클릭에서는 누름과 뗌이 한 프레임에 들어오는데, 메뉴가 열린 바로 그 프레임의 "누름"을 바깥 클릭으로 보고 즉시 닫았다.
   - 수정: 메뉴에 `fresh` 표시를 두어 열린 첫 프레임은 닫기 판정에서 제외 (`studio.rs`).
2. **제목/색상 상자에서 다시 펼친 스티커가 빈 화면으로 남음**
   - 원인: 불투명도 100%인 창에도 레이어드 창(WS_EX_LAYERED)을 적용했는데, 작게 줄었다가 커진 OpenGL 창이 새 프레임을 표시하지 못했다.
   - 수정: 불투명(100%) 창은 레이어드 스타일을 해제하고, 투명도가 100% 미만일 때만 적용 (`win_style.rs`).
   - 남은 위험: 투명도를 낮춘 스티커는 여전히 레이어드 창이므로, 접었다 펼칠 때 같은 현상이 생기면 추가 조치가 필요하다.

## PC에서 확인한 항목

- 더보기 메뉴와 프로젝트 하위 메뉴(오른쪽 표시)
- 우클릭 정렬 메뉴
- 하단 프로젝트·연결 메모 팝업
- 시간 선택 팝업과 ▲▼ 버튼, 달력 머리줄
- 제목 모드 버튼 순서와 툴팁 깜박임 없음
- 색상 상자 한 번 클릭으로 펼치기
- 오늘의 할일 미리보기 편집과 눈 아이콘
- 설정 › 일반의 새 항목들

## 검증

- Windows: `cargo test --release` 100개 통과, `cargo clippy --all-targets` 경고 없음, 릴리스 빌드 성공.
- Linux 테스트 환경에서는 표 이미지 글꼴이 없어 `table_export…` 테스트 1개가 실패한다. 이는 기존 환경 문제이며 Windows에서는 통과한다.

## 참고 (작업 방식)

원격 동기화 도구는 같은 임시 경로를 다시 쓰면 이전 내용을 전달했다. 매번 새 파일 이름으로 올리고, `git write-tree` 해시를 비교해 PC 소스가 일치하는지 확인했다.
