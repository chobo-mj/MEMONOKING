# 작업 기록 — 캘린더 분리창 가로배치 모드 추가 (2026-11-12)

## 배경

백로그 47번: 캘린더 분리창에 가로배치 모드를 추가해 달라는 요청. 이번 요청은 이전 대화 세션이 요약(compaction)된 뒤 다음과 같이 간단히 정리된 형태로만 남아 있었다: "캘린더 분리창 가로배치 모드 추가 (가로배치 모드 전용 아이콘 + 크기 조절 가능한 분할, 초기 너비 1/3, 비례 크기 조절)". 사용자의 원문 메시지는 남아있지 않아, 아래와 같이 해석해 구현했다.

## 가정 (명시)

원문이 없어 다음을 가정하고 구현했습니다. 의도와 다르면 알려주시면 조정하겠습니다.

1. **"가로배치"의 의미**: 기존에는 분리된 캘린더 창이 월/주 그리드 → 선택한 날짜의 메모 목록 순서로 위아래(세로)로 쌓여 있습니다. 가로배치는 이를 좌(그리드) / 우(선택한 날짜의 메모 목록)로 나란히 배치하는 것으로 해석했습니다.
2. **적용 범위**: "캘린더 분리창"이라는 표현을 분리된 캘린더 창(스탠딩 상태 포함) 전용 기능으로 해석했습니다. 메인 창 안에 있는 캘린더 탭이나 "내 작업실"의 미니 캘린더 패널에는 적용하지 않았습니다.
3. **전환 방법**: 분리창 툴바(테마 선택 옆)에 전용 토글 아이콘을 추가해 세로 ↔ 가로를 전환하도록 했습니다. 아이콘은 기존 아이콘 세트에 없어서 새로 그렸습니다 (`Icon::SplitView`, 폭이 다른 두 칸으로 된 사각형).
4. **초기 너비 1/3**: 오른쪽 메모 목록 패널의 초기 너비를 전체 폭의 1/3로 설정했습니다 (그리드가 2/3).
5. **비례 크기 조절**: 창 크기를 조절해도 분할 비율(픽셀이 아닌 퍼센트)이 유지되도록, 분할 값을 픽셀이 아니라 전체 폭 대비 비율(fraction)로 저장했습니다. 사용자가 분할선을 드래그하면 그 비율이 갱신됩니다.

## 구현

- `src/icons.rs`: `Icon::SplitView` 추가 — 세로선 하나로 나뉜 사각형 (오른쪽 칸이 좁게, 1:3 비율 느낌을 주도록).
- `src/calendar_dock.rs`:
  - `Dock`에 `pub horizontal: bool`과 `split_frac: f32` (기본값 1/3) 필드 추가.
  - 분리창 툴바(`calendar_toolbar`)에 `SplitView` 토글 아이콘 추가 — 스탠딩 토글 아이콘 바로 옆.
  - `calendar_horizontal()` 함수 신설: 기존 `agenda_preview`/`views.rs`의 드래그 분할 패턴(`ui.new_child` + `UiBuilder::max_rect` + 드래그 핸들)을 그대로 따라, 왼쪽에 그리드, 오른쪽에 날짜 상세를 각각 스크롤 가능한 패널로 그리고 중간에 드래그 가능한 분할선을 둠.
  - `calendar_window()`에서 `self.cal.horizontal` 값에 따라 기존 세로 `ScrollArea` 경로와 새 가로 경로를 분기.
- `src/views.rs`: 기존 `calendar(ui)` 함수를 `calendar_grid(ui)`(월/주 그리드 + 네비게이션 + 메모 밴드)와 `calendar_day_detail(ui)`(선택한 날짜 제목 + "+ 이 날짜에 스티커" + 메모 목록)로 분리했습니다. `calendar(ui)`는 이제 이 둘을 순서대로 호출하기만 해서, 메인 창의 인라인 캘린더 뷰나 분리창의 기존 세로 배치는 동작이 그대로입니다.

## 검증

- **Linux**: `cargo check`, `cargo clippy --all-targets` 경고 없음. `cargo fmt` 적용. `cargo test` 113/114 통과 (1개 실패는 이 환경에 표 이미지용 글꼴이 없어서 나는, 이전부터 있던 Linux 전용 실패로 이번 변경과 무관).
- **Windows PC 빌드**: `cargo build`, `cargo test` 114/114 통과.
- **실제 PC 조작 검증**: 전역 단축키(Ctrl+Alt+C)로 분리창을 연 뒤,
  - 새 토글 아이콘을 눌러 가로배치로 전환 → 왼쪽 그리드 / 오른쪽 "11월 16일 월" 메모 패널로 정상 분할됨을 확인.
  - 분할선을 드래그해 폭이 실제로 조절됨을 확인.
  - 창을 최대화해도 분할 비율이 유지됨(클리핑되지 않음)을 확인 — "비례 크기 조절" 요구사항 충족.
  - 그리드에서 다른 날짜(12일)를 클릭 → 오른쪽 패널이 즉시 해당 날짜로 갱신됨을 확인.
  - 토글 아이콘을 다시 눌러 세로 배치로 복귀됨을 확인.

## 참고 — 테스트 중 발견한 무관한 환경 이슈

이번 PC 조작 테스트 중, 메인 창이 **최대화(maximize)된 상태**에서 상단 헤더의 아이콘 버튼들(캘린더 분리 아이콘, 새 스티커 아이콘 등 — 이번에 추가한 기능과 무관하게 기존부터 있던 버튼들)이 클릭에 반응하지 않는 현상을 발견했습니다. 창을 최대화 해제한 상태에서는 같은 아이콘들이 정상 동작했습니다. 원격 조작 환경의 윈도우 타이틀바 히트테스트 영역이 맥시마이즈 시 콘텐츠 쪽으로 넓게 겹치는 것으로 보이며, 실제 사용자의 마우스 조작에서도 재현되는지는 확인하지 못했습니다. 코드는 건드리지 않았고, 혹시 사용자도 "최대화 상태에서 상단 아이콘이 안 눌린다"는 증상을 겪으신 적이 있다면 알려주시면 별도로 조사하겠습니다.
