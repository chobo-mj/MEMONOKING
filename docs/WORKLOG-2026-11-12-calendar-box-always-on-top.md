# 작업 기록 — 캘린더 최소화 컬러박스 항상위 해제 (2026-11-12)

## 배경

백로그 48번: 캘린더를 최소화했을 때 나타나는 작은 색상 상자가 다른 창 위에 항상 떠 있어(항상 위, always-on-top) 불편하니 해제해 달라는 요청.

## 원인

`src/calendar_dock.rs`의 `calendar_box()`에서 이 미니 상자 창의 `ViewportBuilder`에 `.with_window_level(egui::WindowLevel::AlwaysOnTop)`가 고정으로 설정되어 있었습니다. 분리된 캘린더 창 본체(세로/가로 배치 모두)는 이 설정이 없어 일반 창처럼 동작하는데, 최소화된 상자만 항상 맨 위에 떠 있던 것입니다.

## 수정

해당 줄을 제거했습니다. 다른 설정(테두리 없음, 크기조절 불가, 작업표시줄 미표시, 투명 배경)은 그대로 유지됩니다.

## 검증

- Linux: `cargo check`, `cargo clippy --all-targets` 경고 없음, `cargo fmt` 통과. `cargo test` 113/114 (환경 전용 글꼴 실패 1건, 무관).
- Windows PC: `cargo build`, `cargo test` 114/114 통과. (상자가 다른 창에 가려지는지는 자동화된 조작 테스트로는 확인이 어려워 빌드/테스트 통과로 검증을 갈음했습니다. 체감 동작이 다르면 알려주세요.)
