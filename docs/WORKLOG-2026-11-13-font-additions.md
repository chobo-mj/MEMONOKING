# #53 폰트 추가: 깨진 개구쟁이 폰트 수정 + 한글 10개 + 영문 5개 추가

## 배경

글꼴 선택 목록에 "개구쟁이"가 있었지만, `main.rs`의 폰트 로더에는 그 이름으로
등록된 파일이 전혀 없었다. `font_id()`는 요청한 폰트 패밀리가 등록돼 있지
않으면 조용히 기본 글꼴(맑은 고딕)로 대체하도록 되어 있어서 — 에러나 깨진
글자가 보이는 게 아니라 "선택해도 아무 효과가 없는" 형태의 버그였다.

## 조사

PC에서 PowerShell로 레지스트리(`HKLM:\...\CurrentVersion\Fonts`)와 실제
`C:\Windows\Fonts` 파일 목록을 직접 확인해, "개구쟁이"라는 이름의 폰트가
이 PC에 설치된 적이 없다는 것과, 실제로 쓸 수 있는 한글 폰트 후보들을
확인했다:

- HY 시리즈 11종(HY중고딕/견고딕/견명조/신명조/궁서B/그래픽M/목각파임B/
  얕은샘물M/엽서L·M/헤드라인M)
- 휴먼 시리즈 6종(휴먼둥근헤드라인/매직체/아미체/모음T&엑스포/옛체/편지체)
- 새굴림, Noto Sans/Serif KR

(참고: 레지스트리에 "NanumGothic" 항목이 있었지만 실제 파일은 존재하지
않는 깨진 항목이어서 후보에서 제외했다.)

## 구현

- **"개구쟁이" 수정**: 실제 설치된 적 없는 이름을 지우고, 실존하는 손글씨
  느낌의 **휴먼매직체**(`HMKMMAG.TTF`)로 교체.
- **한글 10개 추가**: 새굴림, HY중고딕, HY견고딕, HY신명조, HY궁서B,
  HY헤드라인M, 휴먼둥근헤드라인, 휴먼아미체, 휴먼편지체, Noto Sans KR.
- **영문 5개 추가**: Calibri, Georgia, Consolas, Verdana, Segoe UI — 각각
  실제 Bold 파일도 같이 등록해 굵게 서식도 정확히 나오게 했다.
- **코드 정리**: 폰트 목록이 `main.rs`(로더용 튜플 배열)와 `composer.rs`
  (툴바 글꼴 팝업), `desktop.rs`(설정 화면의 글꼴 선택 pill) 세 곳에
  따로 하드코딩되어 있던 것을 `composer::FONTS`(이름, 파일, ttc 인덱스)
  하나로 합치고, `composer::font_choices()`가 "<이름> Bold" 같은 합성
  항목을 걸러내 목록에 보여준다. 세 곳 모두 이 하나의 소스에서 읽으므로
  앞으로 폰트를 추가/수정할 때 한 곳만 고치면 된다.
  - 글꼴 수가 21개로 늘어나 툴바의 글꼴 팝업에는 세로 스크롤 영역(최대
    높이 220px)을 추가했다.

## 검증

- Linux: `cargo build` / `cargo clippy --all-targets`(경고 0) / `cargo fmt`
  / `cargo test` — 123개 중 122개 통과, 나머지 1개는 이전부터 Windows
  전용 글꼴에 의존해 Linux에서 실패하던 테스트(회귀 아님, 아래 참고).
- Windows(PC): `cargo build` / `cargo test` — **123개 전부 통과**.
- 새 테스트: `font_choices()`가 "개구쟁이"를 더 이상 포함하지 않고,
  "<이름> Bold" 합성 항목을 걸러내며, 이름 중복이 없는지 확인.
