# v1.8 PPT·프로젝트 분류·아이콘 도구 검증

2026-11-10, 로컬 Windows. 사용자 PPT 15장과 뒤이어 요청한 고정 분류 제거·아이콘 도구·상단 도움말 제거를 기준으로 확인했다. 이번 결과는 실행 중 UI 프로토타입의 결과이며 저장/보안/알림 제품 인수 결과가 아니다.

## 실제 창에서 확인한 범위

- 달력에 작성일/일정/알람 기준, 작은 왼쪽 상단 날짜, 토요일 파랑/일요일 빨강, 한 줄 메모 제목과 날짜 호버 +가 표시됐다. 긴 일정 제목이 두 줄로 밀리던 문제를 말줄임으로 보정했다.
- 작업실에서 달력을 닫으면 상세 메모 목록과 우측 편집 미리보기로 바뀌었다. 최초 한 행만 보이던 문제를 고친 뒤 여러 날짜/메모 행과 하단 탭까지 표시됐다.
- 방향키 아래를 눌러 선택을 바꿀 때 우측 제목·본문·색상이 해당 메모로 바뀌었다.
- 새 360×360 스티커의 둥근 색상 바탕, 좌상단 +, 더보기·알람·팔레트·압정·완료·접기·닫기를 확인했다.
- 본문에 `#화면검증 `을 입력하자 해당 프로젝트가 만들어지고 명령 문자열이 본문에서 제거됐다. 이후 본문에 첫 줄을 입력하고 Enter를 누르자 빈 제목에 그 줄이 옮겨졌다.
- 첫 탭에 한국어 본문을 입력한 뒤 +로 두 번째 탭을 추가했다. 같은 제목 아래 빈 본문이 나타났고, 두 번째 내용을 입력한 뒤 첫 탭으로 돌아왔을 때 첫 내용이 유지됐다.
- 스티커를 접으면 제목 한 줄이 됐고, 모서리 드래그로 폭을 360에서 320으로 바꿨다. 다시 접어 색상 상자가 된 뒤 더블클릭했을 때 제목·첫 탭 내용·두 번째 탭이 남은 스티커로 복원됐다.
- 전체메모 폴더 화면에서 최상위 새 폴더 생성·이름 입력/확정을 확인했다.
- 빠른 폴더 드래그 시험에서 기본 위젯 드래그가 다른 원본을 잡는 문제가 나와 누른 위치의 원본과 놓은 위치의 폴더를 구분하는 처리로 교체했다. 원래 누른 원본 및 실제 렌더링된 카드/폴더 경계의 회귀시험을 추가했다. 이후 최종 release 창에서 같은 빠른 드롭을 재시험해 메모가 폴더 안에 한 줄로 나타나고 아래 미분류 목록에서는 사라지는 것을 확인했다. 복수 선택 전체 조합은 추가 인수 대상이다.
- 설정의 가로 배치가 본문에 상속되어 한 줄로 늘어나는 문제를 발견하고 세로 본문/유한 폭으로 수정했다. 같은 구조를 재현한 배치 시험을 추가했고 최종 release 창에서도 왼쪽 설정 탐색과 세로 본문이 창 안에 맞게 표시되는 것을 확인했다.
- 사용자가 실행창을 직접 조작하기 시작한 뒤에는 해당 창을 보존했다. 이후 변경은 자동 렌더링 시험과 별도 release 빌드로 확인했다.

## 최신 추가 요청의 확인

- 고정 분류의 모델 필드·상수·편집 선택·관계 보드 필터·목록/카드의 분류 이름을 제거했다. `LABELS`, `COLORS`, `label_filter`, `memo_label`, `board_label`, `Note.label` 참조가 남지 않는지 검색했다.
- 기존 프로젝트 ID와 프로젝트 없음, 메모 자체 색상, 위키/정리 폴더는 유지했다.
- 본문 도구 10개를 벡터 아이콘으로 바꾸고 선택형 도구는 팝업으로 분리했다. 닫힌 도구줄에 Text 도형이 없는지, 360px에서 한 줄(32px 이내), 260px에서 두 줄(64px 이내)인지 egui 렌더링 시험으로 확인했다. 최종 release 스티커에서도 한 줄 아이콘, 늘어난 본문 공간, 글꼴 아이콘의 선택 팝업과 바깥 클릭 닫기를 확인했다. 나머지 팝업 전체 조합은 추가 인수 대상이다.
- 스티커 상단 물음표를 제거하고 더보기의 도움말은 남겼다. 전체 메모 편집창도 더보기에서 도움말을 연다. 메인 작업 공간 도움말은 별개다. 최종 release의 편집창에서 고정 분류가 사라진 것과 스티커 더보기 안의 도움말 항목을 실제 화면으로 확인했다.

## 자동 검증

- `cargo test --locked`: **68개 통과**.
- `cargo clippy --locked -- -D warnings`: 통과.
- `cargo build --release --locked`: 통과.
- 본문 탭의 독립성/첫·마지막 탭 삭제, Unicode 서식 범위, IME 변환 보호, 로마/알파벳 구분, 자동 순번·내어쓰기, 표 구조, 이미지/표 복사·출력, 모든 탭 검색·바꾸기·문자 범위 선택, 저장 댓글 읽기 전용 표시를 포함한다.
- 폴더 생성/형제/순환 방지/일괄 분류, 빠른 드롭과 실제 렌더링 경계, 전체메모 상세 목록 잘림, 설정 세로 배치, 스티커 하단/아이콘 줄 높이, 잠김·삭제·숨김 프로젝트의 모아보기 제외를 포함한다.
- 기존 완료 시각/기간별 완료·댓글, 프로젝트 숨김/삭제, 캘린더 날짜 이동·원본 보존, 다중 스티커, 단축키 중복, 썸네일/일괄 저장 회귀도 유지했다.

## 후속 및 한계

- 저장·암호화·실제 Windows 알림/트레이/자동시작·데이터 폴더 가져오기·자동 보관/삭제는 미연결이다. 잠금은 UI 가림 시뮬레이션이다. 프로그램 종료 시 상태는 초기화된다.
- 투명도는 바탕색 미리보기, 자간은 값 선택 단계다. 전체 위젯의 자간 적용은 후속이다.
- 표/이미지는 해당 탭의 본문 아래 블록이다. 문장 사이의 완전한 리치 블록 배치, 다중 셀 선택/병합은 후속이다. 이미지 원본은 현재 메모리에 유지하며 사용자가 명시적으로 내보낸 파일만 디스크에 남긴다.
- 완전한 한국 음력·대체·임시 공휴일 데이터 팩, 실제 반복 발생 계산과 시리즈 분할 이동은 후속이다. 고정 양력 날짜 표시를 공휴일 전체 검증으로 보지 않는다.
- 모든 실제 IME 조합·접근성 도구·키보드 경로·DPI·다중 모니터·대량 탭/창 운영 조합을 인수한 것은 아니다.
- 원본 PPT와 추출한 참고 이미지는 저장소에 넣지 않는다.

최종 release 확인은 기존 사용 중인 debug 창을 보존한 채 별도 실행했다. 새 검증용 창만 닫았고 기존 메모/메인 창은 남겼다. 동시에 두 프로세스가 열릴 때 Windows 전역 단축키 등록 충돌은 예상되는 OS 동작이므로 새 버전을 사용할 때 이전 실행본을 먼저 종료한다.
