# OmniMemoJang 기능 명세 (SPEC)

최종판이 갖춰야 할 기능과 동작 기준이다. 상태 표시: ✅ 구현됨, 🟡 화면만 있음, ⬜ 미구현.
구조는 [ARCHITECTURE.md](ARCHITECTURE.md)에 있다.

## 1. 공통

| ID | 요구사항 | 상태 |
|---|---|---|
| C-1 | 프로그램 이름은 OmniMemoJang이다. 실행 파일 `omnimemojang.exe`, 창 제목 `OmniMemoJang` | ✅ |
| C-2 | 메뉴창 상단에 타이포그래피 배너를 둔다: 차분한 슬레이트 블루 그라데이션 카드, "Omni·Memo·Jang" 색 구분, 문구 "모든 메모와 일정을 한곳에" | ✅ |
| C-3 | 라이트/다크 모드와 글꼴·글꼴 크기를 바꿀 수 있다 | ✅ |
| C-4 | 메모·프로젝트·연결·위키(탭·폴더)·전체메모 폴더·휴지통·설정이 재시작 후에도 남는다. 2초마다 바뀐 것이 있으면 자동 저장하고, 종료할 때도 저장한다. 그림은 `images\` 폴더에 PNG로 한 번만 저장한다. 읽을 수 없는 저장 파일은 덮어쓰지 않고 `data.broken-*.json`으로 옮긴다 | ✅ (편의기능의 예시 이미지 모음은 저장 대상이 아님) |
| C-5 | 저장 위치: 데이터 `%APPDATA%\OmniMemoJang\data\data.json`(설정에서 폴더 변경 가능), 시작 설정 `%APPDATA%\OmniMemoJang\settings.txt`(첫 화면·숨긴 메뉴·캘린더·데이터 위치·첫 실행 여부) | ✅ |
| C-7 | 첫 실행 때만 나만의 위키의 ‘사용법’ 탭(메뉴별 사용법 메모 10개, 화면 이미지 포함)을 연다. 다음부터는 설정의 첫 화면(기본 내 작업실)으로 시작한다. 사용법 메모는 할 일 목록과 캘린더에 섞이지 않는다. 설정 › 정보의 ‘사용법 보기’로 다시 연다 | ✅ |
| C-6 | 전역 단축키 3개: 빠른 메모(새 스티커), 캘린더 분리창, 새 스티커 | ✅ |

## 2. 메뉴창 (사이드바)

| ID | 요구사항 | 상태 |
|---|---|---|
| M-1 | "빠른 메모" 버튼은 새 스티커 메모를 연다. 예전 빠른 메모 대화상자는 없다 | ✅ |
| M-2 | 메뉴: 내 작업실, 오늘의 할일, 다음에 할일, 캘린더, 전체메모, 나만의 위키, 편의기능 | ✅ |
| M-3 | 설정 › 일반 › 첫 화면: 시작할 때 보여 줄 메뉴를 고른다(숨긴 메뉴는 고를 수 없다) | ✅ |
| M-4 | 설정 › 일반 › 메뉴 숨기기: 내 작업실을 뺀 메뉴를 숨긴다. 보던 메뉴를 숨기면 내 작업실로 돌아가고, 첫 화면이 숨겨지면 내 작업실로 바뀐다 | ✅ |
| M-5 | 검색과 상세 검색, 프로젝트 목록과 프로젝트 관리 | ✅ |

## 3. 스티커 메모

| ID | 요구사항 | 상태 |
|---|---|---|
| S-1 | 접기 순서: 스티커 → 제목 → 색상 상자. 색상 상자는 한 번 클릭하면 펼쳐지고, 끌면 이동한다 | ✅ |
| S-2 | 메모 투명도는 모든 모드(색상 상자 포함)에서 유지된다 | ✅ |
| S-3 | 더보기·우클릭 메뉴는 스티커 밖 별도 창에 뜬다. 하위 메뉴는 오른쪽에, 자리가 없으면 왼쪽에 뜬다 | ✅ |
| S-4 | 하단의 프로젝트 선택과 연결 메모 팝업(메모 색 사각형, 호버 시 진하게) | ✅ |
| S-5 | 중요 메모는 제목 앞에 ★ | ✅ |
| S-6 | 새 스티커 크기 설정(작게 340×240, 보통 360×360, 크게 460×440, 직접) | ✅ |
| S-7 | 매일 오늘 메모 자동 띄우기: 05:00에 날짜가 바뀐다. 지난 미완료 메모와 오늘 메모를 제목 모드로 오른쪽에 정렬한다 | ✅ |
| S-8 | 메모 정렬 모니터 정하기(모니터 2개 이상일 때) | ✅ |
| S-9 | 알람 시각이 되면 Windows 알림 소리와 함께 화면 오른쪽 아래에 항상 위 알림 창을 띄운다(열기·5분 뒤·확인·모두 확인). 꺼져 있던 동안 지난 알람은 다음 실행 때 ‘놓친 알람’으로 보여 준다. 팝업을 끄면 메인 창 알림으로 대신한다 | ✅ (Windows 알림 센터 토스트는 아님) |
| S-10 | 잠금 메모: 비밀번호는 솔트를 붙인 SHA-256 해시로만 저장하고, 비밀번호가 있는 메모는 시작할 때 잠겨 있다. 연 뒤 1·5·15분이 지나면 다시 잠근다 | 🟡 본문 암호화는 아직 |

## 4. 목록 화면 (내 작업실 · 오늘 · 다음 · 전체메모)

| ID | 요구사항 | 상태 |
|---|---|---|
| L-1 | 오늘/다음: 메모를 누르면 오른쪽 미리보기에서 편집하고, 눈 아이콘을 누르면 스티커로 연다 | ✅ |
| L-2 | 미리보기 하단 도구: 알람, 일정, 프로젝트, 연결 메모. 제목 줄 오른쪽에 완료 체크 | ✅ |
| L-3 | 필터: 정기일정 포함, 생성일 기준, 완료 메모 보기 | ✅ |
| L-4 | 찾아 바꾸기: 범위와 프로젝트, 찾기/모두 찾기/바꾸기/모두 바꾸기, 결과 목록 | ✅ |

## 5. 캘린더

| ID | 요구사항 | 상태 |
|---|---|---|
| K-1 | 설정 › 캘린더: 테마(기본·종이·세이지·나이트), 메모 글자 크기(9–18pt), 완료 일정 숨기기, 완료 일정 취소선, 보기 단위(한 달·1주·2주) | ✅ |
| K-2 | 여러 날 이어지는 일정은 색띠 하나로 그린다. 주가 바뀌는 곳에서만 끊고, 끊긴 쪽 끝은 각지게 한다. 겹치면 줄을 나누고, 넘치면 "+N개 더보기"를 보여 준다 | ✅ |
| K-3 | 기간 일정을 완료하면 "이 날짜만" 또는 "전체 일정"을 카드형 창에서 고른다 | ✅ |
| K-4 | 머리줄에 기준 선택(작성일·일정·알람)이 있고, 그 옆에 "근무자 보기" 버튼이 있다 | 🟡 버튼만 있음(동작 없음) |
| K-5 | 근무자 보기: 연결한 엑셀 파일에서 날짜별 근무자를 읽어 캘린더에 표시한다 | ⬜ 후속 구현 |
| K-6 | 1주·2주 보기는 선택한 날이 있는 주부터 보여 주고, 화살표는 1주·2주 단위로 움직인다 | ✅ |

## 6. 캘린더 분리창 · 캘린더 상자 · 스탠딩 캘린더

| ID | 요구사항 | 상태 |
|---|---|---|
| D-1 | 분리창 상단에 큰 "최소화" 버튼. 누르면 달력 아이콘의 컬러 상자로 접힌다 | ✅ |
| D-2 | 상자를 누르면 분리창이 마지막 위치에 열린다. 분리창의 X를 누르면 상자 상태로 돌아간다(상자가 있던 자리) | ✅ |
| D-3 | 상자는 이동할 수 있고, 모서리로 크기를 바꾸며(32–200px), 우클릭 메뉴로 색 변경·캘린더 열기·상자 닫기를 한다 | ✅ |
| D-4 | 스탠딩 아이콘을 누르면 보이는 크기 그대로 바탕화면 배경층에 고정된다. 바탕화면 아이콘이 위에 놓이고, 캘린더 클릭은 무시된다 | ✅ |
| D-5 | 같은 자리의 스탠딩 아이콘을 다시 누르면 원래 위치·제목줄로 돌아와 이동·최소화·닫기가 된다 | ✅ |
| D-6 | 테마 3종(종이·세이지·나이트)과 기본 | ✅ |
| D-7 | 분리창 아무 곳이나 우클릭하면 보기 단위(한 달·1주·2주)를 바꾸는 메뉴가 뜬다. 설정 › 캘린더의 보기 단위와 같은 값이다 | ✅ |

## 7. 나만의 위키

| ID | 요구사항 | 상태 |
|---|---|---|
| W-1 | 상단에 위키 탭이 있다(추가 +, 더블클릭·우클릭으로 이름 변경). 탭마다 자기 폴더 트리를 가진다 | ✅ |
| W-2 | 왼쪽 위 ①은 탭의 트리, 왼쪽 아래 ②는 미분류 위키 메모(최신순) | ✅ |
| W-3 | 오른쪽에 영역 1·2를 나란히 둔다. 고른 영역에 메모가 열린다 | ✅ |
| W-4 | 영역 2의 "빈 메모 열기"로 만든 메모는 위키 속성으로 미분류 맨 위에 보인다. 영역 2를 닫을 때까지 유지되고, 그동안 고른 메모는 영역 1에 열린다. 비어 있는 채로 닫으면 지운다 | ✅ |
| W-5 | 트리에서 우클릭하면 새 위키 노트를 만든다(빈 곳은 탭 최상위, 폴더는 그 안). 새 폴더·이름 바꾸기도 된다 | ✅ |
| W-6 | 탭을 바꾸면 트리만 바뀌고 영역 1·2의 내용은 유지된다 | ✅ |
| W-7 | 끌어서 분류한다: 탭, 트리 빈 곳, 폴더, 폴더 메모 영역, 미분류로 | ✅ |
| W-8 | 영역 머리줄에 댓글 보기, 스티커로 열기, 닫기 | ✅ |

## 9. 완성 기준 (출시 전 확인)

1. ✅ C-4 데이터 저장이 동작하고, 종료·재시작 후 메모·위키·설정이 그대로 남는다.
2. ✅ S-9 알람이 지정 시각에 알림 창과 소리로 뜬다.
3. 🟡 K-4 근무자 보기 버튼이 있다. 동작은 다음 단계에서 한다.
4. ✅ `cargo test --release` 전부 통과, `cargo clippy --all-targets` 경고 0.
5. ⬜ 설치판(`OmniMemoJang-<버전>-Windows-x64-Setup.exe`)과 포터블 ZIP을 GitHub Actions에서 만들고, 설치·제거 검사를 통과한다.
6. ✅ 실제 Windows PC에서 위 항목을 손으로 확인하고 `docs/WORKLOG-*.md`에 기록한다.
