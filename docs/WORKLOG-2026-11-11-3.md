# 작업 기록 — 2026-11-11 (3차)

캘린더, 스탠딩 캘린더, 나만의 위키 개편과 투명도·매일 메모 문제를 반영하고 사용자 PC(Windows 11, 2880×1800)에서 확인한 기록이다.

## 반영한 요청사항

| 항목 | 내용 |
|---|---|
| 투명도 | 컬러박스로 접거나 다시 펼쳐도 메모 투명도를 유지한다. winit이 창 스타일을 다시 쓰면서 레이어드 속성을 지워 버리던 문제로, 매 프레임 확인해 다시 적용한다. |
| 매일 오늘 메모 | 05:00 기준 날짜 계산을 통일했다. `MEMONOKING_TEST_NOW="YYYY-MM-DD HH:MM:SS"`로 테스트 시계를 지정할 수 있어, Windows 시간을 바꾸지 않고도 시험할 수 있다. |
| 캘린더 연속 일정 | 여러 날 이어지는 일정을 하나의 색띠로 표시한다. 주가 바뀔 때만 끊기고, 잘린 쪽 끝은 둥글게 처리하지 않는다. 겹치는 일정은 줄(lane)을 나눠 배치한다. |
| 완료 확인 창 | "이 날짜만"과 "전체 일정"을 큰 카드형 선택지로 바꾸고, 메모 색과 기간을 함께 보여 준다. |
| 캘린더 분리창 최소화 | 큰 "최소화" 버튼을 누르면 달력 아이콘이 그려진 컬러박스로 접힌다. 박스를 누르면 분리창이 원래 위치에 열리고, 분리창의 X를 누르면 다시 박스로 돌아간다. 박스는 마지막 위치를 기억한다. 이동, 모서리 끌기로 크기 조절, 우클릭으로 색 변경·캘린더 열기·박스 닫기를 할 수 있다. |
| 스탠딩 캘린더 | 분리창의 스탠딩 아이콘을 누르면 보이는 크기 그대로 바탕화면 배경층(WorkerW)에 고정된다. 바탕화면 아이콘이 위에 올라오고, 캘린더를 눌러도 아무 일도 일어나지 않는다. 같은 자리의 아이콘을 다시 누르면 원래 위치와 제목줄로 돌아와 이동·최소화·닫기가 가능하다. |
| 캘린더 테마 | 기본 외에 눈이 편한 테마 3종(종이, 세이지, 나이트)을 분리창 상단에서 고를 수 있다. |
| 나만의 위키 | PPT 배치대로 개편했다. "미분류만" 버튼은 삭제했다. 구성은 아래와 같다. |

나만의 위키 개편 세부 내용:

- **화면 배치:** 상단에 위키 탭(추가, 더블클릭으로 이름 변경)이 있고, 왼쪽은 ① 탭별 폴더 트리 위에 ② 미분류 위키를 두었다. 오른쪽에는 영역 1과 영역 2를 나란히 넓게 배치했다.
- **새 위키 노트:** 트리에서 우클릭하면 "새 위키 노트"를 만들 수 있다. 빈 곳에서는 탭 최상위에, 폴더에서는 그 폴더 안에 생기며, 폴더에서는 새 폴더와 이름 바꾸기도 할 수 있다.
- **탭 전환:** 위키 탭을 바꾸면 트리만 바뀌고, 열려 있는 영역 1과 2의 내용은 그대로 유지된다.
- **빈 메모:** 영역 2 중앙의 "빈 메모 열기"로 만든 노트는 위키 속성을 가지며 미분류 맨 위에 보인다. 이 노트는 영역 2를 닫을 때까지 유지되고, 그동안 고르는 메모는 영역 1에 열린다. 비어 있는 채로 닫으면 지워진다.
- **분류:** 미분류 메모를 탭, 트리 빈 곳, 폴더, 폴더 하위 메모 영역으로 끌어 넣어 분류한다.

## PC 테스트 중 발견해 고친 문제

1. **"작게" 스티커 크기 설정이 적용되지 않음**
   - 원인: 작게 크기의 너비(280px)가 스티커 최소 너비(340px)보다 작아 값이 잘렸다.
   - 수정: 340×240으로 바꿨다.
2. **캘린더 박스를 끌어도 움직이지 않음**
   - 원인: 빠른 드래그에서는 OS 이동이 시작되지 않았다.
   - 수정: 스티커와 같은 네이티브 이동 처리(`native_window::State`)를 쓰도록 바꿨다.
3. **스탠딩 해제 클릭을 인식하지 못함**
   - 원인: 바탕화면이 포커스를 가진 동안에는 마우스 상태 폴링(`GetAsyncKeyState`)으로 클릭을 잡지 못했다.
   - 수정: 저수준 마우스 훅(`WH_MOUSE_LL`)을 전용 스레드에서 사용한다. 해제하면 훅도 제거된다.
4. **스탠딩 해제 후 창이 제목줄 높이만큼 내려감**
   - 수정: 고정 전의 바깥 창 크기·위치로 복원한다.

## PC에서 확인한 항목

- 테스트 시계 04:59:00 → 11일 메모 3개가 제목 스티커로 오른쪽에 정렬됨 → 05:00이 지나자 12일 메모가 추가되고 다시 정렬됨
- 투명도 60% 메모를 컬러박스로 접었다가 펼친 뒤에도 투명도가 유지됨
- 분리창 테마 변경 → 최소화 → 박스 이동·크기 조절·색 변경 → 박스 클릭으로 열기 → X로 박스 복귀
- 스탠딩 고정(바탕화면 아이콘이 위에 표시됨) → 아이콘을 다시 눌러 원래 자리로 해제
- 위키 화면, 메모 열기 (로컬 화면에서 빈 메모 열기와 트리 우클릭 메뉴도 확인)
- 완료 확인 창과 연속 일정 색띠는 로컬 화면에서 확인

## 검증

- Windows: `cargo test --release` 103개 통과, `cargo clippy --all-targets` 경고 없음.
- Linux에서는 Windows 대상 `cargo clippy --target x86_64-pc-windows-msvc`로 Windows 전용 코드도 미리 검사했다.

## 알아 둘 점

- 데이터는 아직 저장되지 않으므로 앱을 다시 켜면 설정, 위키 탭, 캘린더 박스 위치가 초기화된다. 이는 기존 구조와 같다.
- 스탠딩 캘린더는 Explorer의 WorkerW에 붙인다. Explorer가 다시 시작되면 고정이 풀릴 수 있다.
