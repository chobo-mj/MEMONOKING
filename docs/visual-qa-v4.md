# v1.6 분류·기간·작은 창 검증

검증일: 2026-11-09, 로컬 Windows. UI 프로토타입의 실행 중 상태와 명령 검증이다.

## 실제 화면·입력으로 확인

- 프로젝트 필터에서 `프로젝트 없음`을 선택하면 미지정 메모가 표시됨.
- 일정 없는 `떠오른 아이디어 모으기`를 달력에 드래그해 11월 17일 일정 자동 지정. 같은 제목과 원본으로 목록/캘린더 갱신.
- 위키에서 폴더 선택 없이 새 폴더를 두 번 만들어 최상위 형제 폴더 두 개 생성.
- 새 폴더 3을 폴더 2 안으로 드래그해 계층 변경.
- 오른쪽 위키 메모를 왼쪽 하위 폴더로 드래그해 분류. 트리 제목 클릭으로 오른쪽 본문/댓글 보기 전환.
- 댓글 입력·추가 후 트리에 `댓글 1개` 표시.
- 위키 목록 클릭으로 독립 편집창 열림. 1~5일 드롭다운에서 3일을 선택하고 완료 범위 대화상자 표시. 하루만 완료 후 `기간 3일 · 1일 완료` 표시.
- 색상 네모의 중앙 드래그로 위치가 바뀜. 모서리 드래그로 48×48→34×34 크기 변경. 중앙 클릭으로 전체 편집창 복원.
- 중요·위키 옵션이 같은 줄에 나란히 배치됨.
- 오늘 화면에서 날짜 그룹보다 위에 중요 모음이 별도로 표시됨.

## 자동 검증

`cargo test --locked`: 32개 통과. 신규 검증은 프로젝트 없음과 전체 필터의 구별, 역방향 날짜 정렬, 형제 폴더 생성/폴더 순환 방지, 위키 드래그 분류와 원본 미복제, 폴더 이동과 메모 데이터 독립, 기간의 중간 날짜 이번만/이후 완료·취소 대기, 월말/연말의 3일 발생, 기간 이동 시 완료·댓글 연결 보존, 정리 후 썸네일 보존과 다른 백업의 안전 거부, 작은 창 좌표·크기 한계, 선택된 발생 건만 완료 시각 수정 허용을 포함한다.

`cargo clippy --locked -- -D warnings`와 로컬 빌드 성공. 원본을 비운 이미지의 백업 파일은 자동 시험에서 임시 파일을 생성해 검증했고, 시험 파일은 시험이 끝난 뒤 제거했다.

## 남은 확인과 범위

- 본문과 댓글은 같은 텍스트 입력 위젯이다. 리치 본문 블록/이미지/표 엔진은 아직 연결 전이며 댓글에만 별도 완성 기능이 있다고 하지 않는다.
- 원본 이미지 클릭 복사·아이콘 저장·썸네일 백업 팝업은 연결했으나 실제 사용자 경로의 파일 대화상자 전체 흐름/사내 클립보드 제한을 인수하지 않았다.
- 전체 기간 드래그는 기간 전체를 같은 거리만큼 이동한다. 반복 일정 엔진의 이번만/이후 시리즈 이동과 별개다.
- 여러 배율·모니터, 창이 화면 밖으로 이동하는 모든 경우, 긴 폴더/댓글 트리 대용량은 추가 인수 대상이다.
- 기간 길이 축소 시 이미 완료된 과거 발생의 영속 보존은 제품 저장 모델에서 보강해야 한다.
- 앱 상태·폴더·댓글·이미지 백업 경로는 종료하면 초기화된다. 명시적으로 내보낸 이미지 파일만 디스크에 남는다.
