# #52 표 붙여넣기: 실제 셀 병합 + 커서 위치에 삽입

## 배경

1차 수정(이전 작업록 참고)은 "이미지 + 깨진 표"가 같이 붙는 레이스 컨디션과
TSV 전용 파싱의 한계만 고쳤다. 사용자가 실제 PC에서 테스트한 뒤 스크린샷과
함께 거부했다:

> "이렇게들어가는건 표가 아니야. 그리고 커서가 위치한곳에 표가 붙어야하는데.
> 이상한 위치에 표가 붙었어. 단순 격자가 아니라 진짜 표를 지원하게 해."

즉 두 가지가 더 빠져 있었다:

1. 표가 커서 위치가 아니라 항상 본문 맨 아래에 붙음 (그림과 다르게 동작).
2. `colspan`을 "빈 셀로 채우기"만 했을 뿐, 실제 셀 병합(시각적으로 하나의
   큰 셀)이 아니었고 `rowspan`은 전혀 지원하지 않았음.

범위를 확인하기 위해 사용자에게 다시 물었고(위치만 / 위치+병합+컬럼폭 모두
한번에 / 뒤로 미루기), **"위치+병합/컬럼폭까지 한번에"**로 답변받아 전체를
이번 라운드에서 처리했다.

## 구현

### 데이터 모델

- `Cell`에 `col_span`, `row_span`, `covered` 추가. `covered`인 칸은 자기
  텍스트를 갖지 않고, 그리는 대상도 아니고, 포커스도 받지 않는다 — 병합
  밑에서도 격자 자체는 사각형을 유지해 행/열 인덱스가 정상 동작한다.
- `Table`에 `id`(그림처럼 고유 식별자)와 `positioned`(그림처럼 본문 텍스트
  안의 특정 위치에 자리잡았는지) 추가. `positioned == false`는 병합/위치
  기능 이전에 만들어진(또는 그렇게 마이그레이션된) 표로, 예전처럼 본문
  아래에 항상 표시된다.
- `width: f32` 단일 값 → `col_widths: Vec<f32>`로 교체(열마다 폭 보존).

### 커서 위치에 삽입 (그림과 같은 메커니즘)

- `Tab::insert_table`이 `insert_picture`와 똑같은 방식으로 동작: 새 id를
  받고, 본문의 해당 위치에 플레이스홀더 문자 하나를 넣고, `positioned =
  true`로 표시한다.
- 붙여넣기 처리기가 이제 이 함수를 호출해 커서가 있던 자리에 정확히
  삽입한다. 클립보드에 실제 HTML 표가 있으면 그걸 파싱하고, 없으면 TSV로
  내려간다.
- `table_sizes` / `inline_tables` / `paint_tables` 세 함수를 그림의
  `picture_sizes` / `inline_pictures` / `paint_pictures`를 거의 그대로
  본떠 추가했다. 레이아웃 잡에 표 크기만큼 투명한 자리(스크롤 가능한
  최대폭으로 제한)를 예약해 두고, 그 위치에 `egui::Area`로 실제 상호작용
  가능한 표 위젯을 떠서 그린다. 표가 줄바꿈으로 넘어가도 그림처럼 자기 줄의
  바로 아래에 그려진다.

### 실제 셀 병합

- `Table::from_html`을 다시 작성: 표준 HTML 표 레이아웃 알고리즘(각 열마다
  "앞으로 몇 행 더 덮여 있는지"를 추적하는 `blocked` 배열)으로 `colspan`/
  `rowspan`을 진짜 병합으로 반영한다. 병합된 영역의 소유 셀만 텍스트/서식을
  갖고, 나머지는 `covered`로 표시된다. `<br>`은 줄바꿈으로 변환된다.
- 그리드 렌더링은 `egui::Grid`로는 셀 병합을 표현할 수 없어서(각 칸이
  정확히 하나의 격자 슬롯만 차지한다는 전제라서), 직접 좌표를 계산해
  배치하는 방식(`table_widget`)으로 바꿨다. `covered` 칸은 아예 그리지
  않고, 소유 셀은 자신이 덮는 모든 열/행의 폭/높이 합으로 그려진다.
  `show_blocks`(본문 아래에 항상 표시되는 표)와 인라인 위치 표시 양쪽이
  이 하나의 함수를 공유한다.
- 셀 우클릭 메뉴에 "오른쪽 셀과 병합" / "아래 셀과 병합" / "병합 해제"를
  추가했다.
- 행/열 추가·삭제는 병합이 새 모양 밖으로 걸치는 경우를 추적하지 않는 대신,
  구조가 바뀔 때마다 그 표의 모든 병합을 해제해 안전하게 간다(복잡한
  부분 병합 유지 로직 대신 선택한 단순한 트레이드오프).

### 저장 형식 마이그레이션

- `storage.rs`에 `BlockRec::TableV2`를 새로 추가(열 단일 폭 대신
  `col_widths`, 셀마다 `col_span`/`row_span`/`covered`, `id`, `positioned`
  포함). 예전 `BlockRec::Table`은 그대로 남겨 과거 저장 파일이 깨지지 않게
  했고, 불러올 때 `positioned: false`와 균일한 `col_widths`로 자동
  변환한다. 저장은 항상 `TableV2`로 한다.

### 표 복사(HTML로 내보내기)도 함께 수정

- `table_html`(표 복사 버튼)이 이제 `covered` 칸을 건너뛰고 실제
  `colspan`/`rowspan` 속성을 내보내며, 셀 안의 줄바꿈을 `<br>`로 바꾼다.
  병합한 표를 복사해도 Excel/워드 쪽에서 똑같이 병합된 표로 붙는다.
