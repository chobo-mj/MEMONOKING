# Windows 시각 검증 기록

검증일: 2026-11-08. 로컬 Windows에서 Rust 디버그 빌드 실행 후 실제 창과 화면을 확인했다. 전체 기능 구현 완료나 모든 환경의 호환성을 뜻하지 않는다.

## 확인한 항목

- 한국어 제목·본문·메뉴의 표시와 제목 줄바꿈.
- 빠른 메모에 `시각 검증용 메모 — 한글 입력 확인` 입력 후 추가: 목록에 새 메모가 나타나고 입력칸이 초기화됨.
- 표 모아보기, 이미지 카드, 링크·즐겨찾기 예시 화면으로 전환.
- 설정 열기와 다크 모드 전환, 사이드바·본문·커버의 색 대비.
- 좌측 메모와 우측 캘린더 분할 표시, 균일한 날짜 칸.
- 메모와 캘린더의 실제 분리창 열기 및 닫기.
- 분리 메모에서 스크롤하여 하위 메모 및 추가 버튼에 접근.
- 수정 후 로컬 `cargo build` 성공, 컴파일 경고 없음.

## 수정한 문제

- 작은 기본 글꼴과 과도한 본문 너비: 글꼴 크기 확대, 본문 최대 너비 및 여백 적용.
- 작은 분리창 하단 내용 접근 불가: 세로 스크롤 및 최소 창 크기 적용.
- 날짜별 칸 너비 불균형: 그리드 전체에서 같은 너비 사용.
- 다크 모드에 밝은 배경이 남는 문제: 사이드바·커버·카드 글자색 조정.
- 시작 시 기본 테마 선택색 복원: 프레임에 현재 테마를 일관되게 적용.
- 좁은 영역의 제목·메타정보 넘침 완화: 여러 줄 제목과 메타정보 줄바꿈 적용.

## 검증의 한계

- 단일 현재 Windows 환경에서 확인했다. 다중 모니터, 여러 배율, 다른 Windows 버전 및 보조공학 전체 조합은 검증하지 않았다.
- 한글 문자열 입력은 확인했으며 실제 키보드 IME 조합 과정 전체를 검증하지 않았다.
- 창의 수동 크기 조절 전 구간과 모든 최소 크기 조합은 별도 검증이 필요하다.
- 이미지 영역은 색상 카드이며 표와 링크는 예시 데이터다. 외부 브라우저 실행은 없다.
- 캘린더 주/일 버튼은 외형 시연이다. 실제 드래그 이동·반복 일정 계산·공휴일·알림은 아직 없다.
- 저장·연결·백업은 요청 범위에 따라 구현하지 않았다. 종료하면 입력은 초기화된다.
