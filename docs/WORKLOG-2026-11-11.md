## 추가 요청 반영

1. **메모를 항상 스티커로 열기** — 설정 › 메모창에 옵션 추가, 기본값은 켜짐. 스티커 제목줄에 편집 버튼을 추가했고, 메모 편집 창은 이 버튼으로 엽니다.
2. **둥근 모서리 밖 검은색 제거** — 위 `win_style` 참고.
3. **메모 편집 창 바탕색** — 편집 창도 스티커와 같은 메모 색을 쓰고, 본문 영역은 옅은 흰색 면과 테두리로 구분.
4. **설정 창이 메인 창 뒤에 숨는 문제** — `ui::raise()` 추가. 설정 버튼을 누르면 이미 열린 설정 창도 앞으로 옵니다. 알람·일정·잠금 등 다른 팝업도 다시 열면 앞으로 옵니다.
5. **미리보기 너비에 맞춰 목록이 줄어듦** — 목록 표의 최소 너비를 881에서 560으로 줄여, 미리보기를 넓히면 제목·본문 열이 함께 줄어듭니다.
6. **목록 열 간격** — 알람 96, 생성일 58, 일정 86으로 좁히고, 남는 너비는 모두 제목(38%)과 본문에 배분.
7. **스티커 상단 아이콘 재배치와 일정 팝업**
   - 팔레트를 + 옆으로 옮기고, 그 자리에 일정 아이콘을 추가 (마우스를 올리면 현재 일정이 표시됨).
   - 일정 팝업에서는 시작·종료 날짜와 시각, 반복(안 함·매일·매주·격주·매월)을 정합니다. 매주·격주는 요일을 여러 개 고를 수 있고, 매월은 날짜 기준이나 'N번째 주 X요일'(첫째~넷째, 마지막) 기준을 고릅니다.
   - 반복 규칙은 `src/repeat.rs`의 `Repeat`이고, `Note::occurs()`가 이를 반영해 달력과 목록에 반복 일정이 표시됩니다.
8. **전체메모 · 나만의 위키 · 편의기능 재디자인**
   - 공통 부품 추가: `section_header`, `card`, `list_row`, `tree_row`, `empty_state`
   - 폴더 보기: 폴더 트리 카드(아이콘·개수 표시)와 미분류 메모 카드(색 점·날짜 표시), 빈 미리보기 안내
   - 관계 보드: 카드 머리줄 정리, 본문 2줄, 메타 한 줄, 완료·열기·연결 버튼 정리, 카드 높이 축소
   - 위키: 왼쪽은 폴더 트리, 오른쪽은 위키 목록(제목, 폴더·날짜·첫 줄)과 읽기 화면. 폴더를 고르면 그 폴더의 위키만 보입니다.
   - 편의기능: 업무일지 카드형 기록, 표 모아보기에 검색창과 카드, 표·이미지가 없을 때 빈 화면 안내('예시 보기' 버튼 포함), 즐겨찾기 목록, 휴지통 빈 화면 안내

## 확인

- `cargo test` 98개 모두 통과 (Windows PC), `cargo clippy` 경고 없음 (Linux와 x86_64-pc-windows-msvc)
- PC에서 직접 실행해 확인한 것:
  - 메모가 스티커로 열림
  - 투명도 60~40%에서 뒤 화면이 비침
  - 메인 창을 최소화해도 스티커가 바탕화면에 남음
  - 둥근 모서리 밖에 검은색이 없음
  - 일정 팝업 '매월 둘째 주 수요일'이 달력에 반영됨
  - 편집 창 바탕이 메모 색과 같음

## 남은 사항

- 반복 일정의 완료 표시는 아직 메모 단위입니다. 반복 회차 하나를 완료하면 모든 회차가 완료로 보입니다. 회차별 완료는 반복 엔진 단계에서 연결할 예정입니다.
- 데이터 저장(영속화)은 아직 없어서, 프로그램을 끄면 메모가 초기화됩니다 (기존과 같음).
- Windows의 창 전체 투명도는 글자도 함께 투명하게 만듭니다. Windows 스티커 메모 앱과 같은 방식입니다.
