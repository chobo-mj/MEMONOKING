# 2026-11-13 캘린더 우클릭 메뉴: 분리하기 추가 (#56)

## 요청
"캘린더 우클릭 메뉴 (한달/1주/2주보기 + 캘린더 분리하기)" — 캘린더 창 우클릭 메뉴에 보기 단위
전환과 "캘린더 분리하기" 항목이 있어야 한다는 요청.

## 조사
- `src/calendar_dock.rs`의 `calendar_view_menu()`에 "한 달 보기"/"1주 보기"/"2주 보기"는 이미
  구현되어 있었다(우클릭 → 보기 단위 전환). 이번 요청에서 새로 필요한 부분은 "캘린더 분리하기"
  항목뿐이었다.
- "분리하기"에 대응하는 기능을 찾아보니, 도구줄의 "스탠딩" 아이콘(바탕화면에 고정)이 캘린더를
  일반 앱 창에서 분리해 데스크톱에 독립적으로 고정하는 기능이었다. 우클릭 메뉴에는 이 기능으로
  가는 경로가 없었다.

## 가정 (명시)
- "캘린더 분리하기"는 기존 "스탠딩(바탕화면 고정)" 기능과 동일한 동작으로 해석했다. 우클릭
  메뉴에서도 같은 동작을 트리거할 수 있게 접근 경로를 하나 더 만든 것이다. 만약 "분리하기"가
  스탠딩이 아니라 완전히 다른 기능(예: 독립된 두 번째 캘린더 창 띄우기)을 의미한 것이었다면
  알려주시면 다시 작업하겠다.

## 구현
- `src/calendar_dock.rs`
  - `calendar_view_menu()`가 `bool`을 반환하도록 바꿔, "캘린더 분리하기" 항목 클릭 여부를
    호출자에게 알린다. 보기 단위 메뉴 아래 구분선과 함께 "캘린더 분리하기" 버튼을 추가했다.
  - `calendar_window()`를 리팩터링해 도구줄 아이콘 클릭과 우클릭 메뉴 클릭이 같은 "스탠딩으로
    고정" 경로를 타도록 했다(기존에는 핀 고정 로직이 도구줄 콜백 안에만 있어 메뉴에서 재사용할
    수 없었다. `stand_rect`를 외부 변수로 끌어올려 두 경로 모두에서 쓰도록 정리).

## 시험
- Linux: `cargo build`, `cargo clippy --all-targets`(경고 없음), `cargo fmt --check` 통과,
  `cargo test` 125개 중 124 통과(윈도우 전용 글꼴 경로 테스트 1개는 기존 실패, 회귀 아님).
- 이 파일은 기존에도 단위 테스트가 없다(실제 OS 창 핸들(HWND)에 의존하는 로직이라 Linux에서
  재현 불가). 비주얼 확인은 이번 라운드를 모두 마친 뒤 한 번에 요청할 예정.
