# 0.2.0 디자인 디테일·창 조작·시험 배포 검증

2026-11-10 · Windows x64 · 화면과 조작 미리보기. 원본 요구사항 PPT 15장과 추가 디자인 PPT 3장을 기준으로 검토했다. 원본 문서와 추출 이미지는 저장소/배포판에 포함하지 않는다.

## 변경과 코드 검토

- 작업실 상세 보기를 표시/완료/제목/내용/알람/생성일/일정/삭제의 가로 8열로 교체했다. 우측 편집 미리보기는 약 300 논리 픽셀을 사용하며 표만 가로 스크롤한다. 헤더/본문 열 위치, 좁은 창의 마지막 열 접근, 복수 행 표시를 렌더링 시험으로 확인했다.
- 메모는 상단 헤더·제목/속성·본문·하단 탭/아이콘으로 구분했다. 시작/종료 날짜와 시간은 달력에서 선택하고 프로젝트만 분류 옵션으로 남겼다. 폴더 정리는 별도 전용 화면에 유지한다.
- 본문과 하단 도구를 분리해 본문만 스크롤한다. 탭 아래 구분선과 아이콘 줄, 우측 연결 메모 화살표를 둔다. 자동숨김 스티커는 탭만 최하단에 표시한다. 최대화/복원과 더보기 도움말을 제공한다.
- 실시간 관측 크기를 매 프레임 다시 요청하던 코드와 수동 이동/크기 계산 경로를 제거했다. 초기/모드 전환의 크기 요청과 Windows 네이티브 BeginResize/StartDrag를 사용한다. Shift 상자는 조작 종료 후 안정된 위치에 한 번만 정사각형을 적용한다.
- 추가 검토에서 닫은 창 재생성 시 저장 크기 누락, 상태 메시지가 있을 때 하단 도구 잘림, 완료시각 선택 중 다른 완료 발생으로 이동하면 잘못 적용될 수 있는 경로를 발견해 각각 수정하고 회귀시험을 추가했다.
- 명시적 종료 날짜를 통해 5일을 넘는 기간도 표현한다. 단일 완료 메모의 종료 시각만 수정했을 때 완료 상태를 보존하고, 단일/기간 전환과 일정 이동에서도 완료 시각의 의미를 유지한다.

## 자동검사

- `cargo fmt --all --check`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo test --locked`를 실행한다. 최종 시험 개수와 빌드 결과는 아래 최종 결과에 기록한다.
- 400일 일정, 역순 시작/종료 정규화, 기간 이동/축소/확장, 완료 해제 후 기록 부활 방지, 독립 창/탭·댓글·프로젝트·드래그·복사/내보내기 회귀를 포함한다.
- 네이티브 크기 변경 중 수동 geometry 명령이 발생하지 않고 종료 보정은 한 번만 수행되는지 확인한다. 이 시험은 실제 화면의 떨림 관찰을 대신하지 않는다.

## 실제 창 검증 상태

새 실행본은 기존 사용 중인 debug 실행본과 분리해 열었다. 현재 Windows 잠금 화면이 확인되어 입력을 중지하고 잠금 해제를 요청했다. 이번 0.2.0의 실제 크기 변경·최대화/복원·하단 배치 화면 검증은 아직 완료로 판정하지 않는다. 이전 화면 검증은 [v1.8 기록](visual-qa-v6.md)에 별도로 보존한다.

## 배포 검증 상태

설치형/포터블/체크섬을 만드는 Windows 워크플로를 준비했다. 정적 CRT 의존성, 파일 허용 목록, 현재 사용자 설치·바로가기·제거, 최종 해시 확인을 통과한 뒤 사전 배포한다. CI 실행과 공개 첨부파일 확인 전에는 설치파일 배포 완료로 기록하지 않는다.

## 최종 결과

- 로컬 형식 검사와 Clippy 경고 0개 검사를 통과했다.
- `cargo test --locked`: **82개 통과, 실패 0개**.
- 정적 CRT x64 release 빌드와 dumpbin 직접 의존성 검사를 통과했다. 별도 Visual C++ 런타임 DLL이 나타나지 않았다.
- 실제 창 재검증과 GitHub 설치/제거·공개 릴리스 검증은 현재 대기 중이다.

## 범위와 추가 인수

프로그램 종료 시 데이터와 설정은 초기화된다. 저장/백업·암호화·실제 Windows 알림/트레이/자동시작, 완전한 한국 공휴일과 반복 발생 엔진은 후속이다. 잠금은 UI 시뮬레이션이다. 서로 다른 DPI/모니터, 원격 세션, 대량 창·탭, 모든 IME와 접근성 조합은 추가 인수 대상이다. 사내 PC 동작은 해당 환경에서 별도로 확인해야 한다.
