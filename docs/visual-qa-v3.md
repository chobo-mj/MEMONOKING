# v1.5 화면·동작 검증 기록

검증일 2026-11-09, 로컬 Windows. 제품 전체 인수시험이 아닌 실행 중 프로토타입 검토다.

## 실제 화면에서 확인한 항목

- 왼쪽 `나만의 위키`와 네 화면을 묶은 `편의기능` 메뉴.
- 일반 목록의 편집 버튼에서 실제 별도 메모 창이 생성됨.
- 접기 Full→제목 한 줄(380×42)→색상 네모(48×48)→네모 클릭 후 Full 복원.
- 편집창의 항상 위에·기본색/임의색 메뉴·중요 옆 위키·폴더 선택 UI.
- 시간 입력란 클릭 시 해당 별도 창 안에 달력과 시/분 선택기가 나타남.
- 위키의 폴더 제목·설명·메모 선택과 우측 제목/본문·전용 댓글 입력 영역.
- 수집함의 관계/트리보기·확대 조절·자동정렬 UI 및 고정 크기 화살촉.
- 편의기능의 일지/표/이미지/즐겨찾기 탭과 갤러리 용량·날짜 필터·파일 작업 버튼.

## 자동 검증

18개 테스트 통과: 이전 드래그·완료 계약, 복수 부모 모든 경로의 순환 차단, 확대 좌표의 카드 이동, 프로젝트 이름만 삭제/메모 포함 삭제, 숨김 검색 예외, #프로젝트 첫 줄 처리, 위키/일지 댓글 분리, 보드 자동정렬의 관계 보존, 안전한 HTML 링크 파싱, 표 PNG·예시 이미지 생성, 기존 파일 덮어쓰기 거부.

`cargo build --locked`, `cargo clippy --locked -- -D warnings` 통과. 계획 16~19에 제품 인수시험과 새 데이터/마이그레이션 계약을 추가했다.

## 수정한 화면 문제

- 접힌 창이 기존 최소 크기에 묶이지 않도록 모드별 최소/최대/장식을 함께 변경.
- 날짜 선택기에 호출 창 소유자를 부여하여 다른 창에 뜨지 않도록 함.
- 보드 Scene 변환과 드래그 판정을 연결하고 실제 배율 표시를 동기화.
- 이미지 갤러리 카드의 내용 배치를 세로로 고정하여 이미지 높이 어긋남 수정.
- 생성시각 표시 때 카드 높이를 늘려 완료/연결 버튼 잘림 방지.

## 한계

- Ctrl+휠의 물리적 조합 입력, 여러 배율/모니터, 항상 위에의 다른 앱과의 전체 조합, 네이티브 파일 대화상자에서 실제 사용자 경로 선택 후 출력/재로딩은 전체 UI 검증하지 않았다. 확대 좌표는 입력 회귀 테스트로 확인했다.
- 클립보드 복사·파일 저장·HTML 반입은 실제 연결했지만 사내 보안 PC에서의 허용/차단 처리는 추가 인수가 필요하다.
- 표·이미지·즐겨찾기 화면은 예시 데이터 기반. 기존 본문 첨부 엔진과 연결된 완성 제품이 아니다.
- 앱 데이터·폴더·댓글·프로젝트·외부 보관 경로는 실행 중 메모리에만 남는다. 명시적으로 내보낸 이미지 파일만 디스크에 남는다.
- 현재 일반 편집창은 활성 메모 하나를 표시한다. 여러 메모 동시 독립 편집은 제품 계획에 남아 있다.
- 일지 댓글은 현재 메모별이며 반복 회차별 완료 사건 연결은 후속 구현이다.
