# 스티커 메모 빈 공간 더블클릭 → 전체화면 토글

## 배경

요청: 펼쳐진 스티커 메모 창의 빈 공간을 더블클릭하면 전체화면으로 전환되고,
다시 더블클릭하면 원래 크기로 복원되어야 한다.

## 가정

- "빈 공간"의 범위를 스티커 창 전체(제목 입력창, 본문 텍스트 영역 포함)로 넓히면
  더블클릭이 "단어 선택" 같은 기존 텍스트 편집 동작과 충돌할 수 있다. 코드를 보면
  `memo_header`(아이콘 줄)의 드래그/우클릭-메뉴용 빈 간격 레이블은 스티커 모드에서만
  텍스트가 비어 있고(편집 창 모드에서는 "메모 편집" 글자가 들어 있음), 이미 드래그
  이동과 우클릭 정렬 메뉴로 쓰이고 있는 유일하게 명확한 "빈 공간"이다. 이 영역을
  더블클릭 대상으로 삼기로 가정했다.
- 본문 텍스트 영역(실제 메모 내용을 적는 칸)은 이번 범위에서 제외했다. 더블클릭으로
  단어를 선택하는 표준 텍스트 편집 동작을 그대로 유지하기 위함이다.
- 토글 대상은 네이티브 창 전체화면(`ViewportCommand::Maximized`)으로, 이미 편집
  창(`Mode::Editor`) 상단 아이콘에 있는 최대화/복원 버튼과 같은 메커니즘을 재사용했다.

## 구현

`src/studio.rs`의 `memo_header()`에서, 헤더 아이콘 줄의 빈 간격 레이블(`response`)에
대해 `mode == Mode::Sticker`일 때 `response.double_clicked()`를 검사해 네이티브
창의 최대화 상태를 토글하도록 8줄을 추가했다. 창 가장자리 드래그 리사이즈 중이면
`w.native.cancel()`로 먼저 취소한다(편집 창의 기존 최대화 버튼과 동일한 처리).
