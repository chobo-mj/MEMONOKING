# 일정 중심 레이아웃 시각 검증 v2

검증 기간: 2026-11-08~09, 로컬 Windows. 프로토타입의 메모리 동작 확인이며 제품 기능 전체 인수시험은 아니다.

## 실제 화면에서 확인한 결과

- 작은 숫자가 왼쪽 상단에 위치하는 월 캘린더와 제목 말줄임 표시.
- 내 작업실의 날짜·시간순 목록과 오른쪽 캘린더 나란히 표시.
- `디자인 방향 정리`를 목록에서 11월 10일로 드래그: 캘린더와 목록 모두 10일로 반영.
- 위 일정을 캘린더 안에서 11월 20일로 드래그: 원본 일정 날짜와 목록이 20일로 반영.
- 수집함 카드 자유 이동: 카드 위치 변경, 연결선 유지.
- `화면 흐름 검토` 손잡이를 다른 카드에 드롭: 상위 메모명 표시 및 부모 관계 생성.
- 카드 완료 체크: 업무일지에 제목·본문·체크 시각 표시.
- 완료 시각을 `2026-11-07 17:30`으로 보정: 8일 일지에서 제외되고 11월 월별 조회에는 수정된 시각으로 표시.
- 전역 단축키 기본값 등록 성공 표시. Chrome이 앞에 있는 상태에서 Ctrl+Alt+N을 눌러 빠른 메모 창이 나타남. Ctrl+Alt+C로 실제 분리 캘린더 창 생성 확인.
- 빌드 성공. `cargo test`: 6개 통과.

## 검증 중 수정한 결함

- 캘린더 일정 위젯이 부모 배치 커서를 바꿔 상세 목록이 날짜 칸 위에 겹침: 별도 자식 UI에 절대 위치로 배치하여 해결.
- 빠른 드래그의 시작/종료가 한 프레임에 모일 때 누락: 입력 이벤트 순서와 안정된 원본 ID를 추적하여 수정, 회귀 시험 추가.
- 화면보다 큰 초기 창 크기를 축소하고 캘린더/본문 각각 세로 스크롤 유지.
- 일부 글꼴에서 손잡이/체크 기호가 빈 사각형으로 나옴: 손잡이와 완료/상위 관계 표시를 단순 문자·텍스트로 교체.
- 전역 단축키 복구 일부 실패 시 잘못된 동작으로 매핑될 가능성: 부분 복구를 비활성 처리하고 실패를 명시.

## 남은 검증 및 구현 범위

- 다중 모니터·배율별 히트영역, 다른 PC/사내 보안 정책, 실제 키보드 IME 조합은 추가 검증 필요.
- 프로젝트 묶기·선택/라벨 필터·연결 해제·단축키 변경의 모든 조합과 OS 충돌은 전체 UI 회귀를 수행하지 않았다. 관계 핵심 불변조건은 자동 시험으로 확인했다.
- 네이티브 창 사이를 넘는 드래그는 아직 지원하지 않는다. 같은 창 안에서 목록/캘린더 이동을 확인했다.
- 반복 발생 계산, 범위 선택 이동, 알림, 저장·복원은 미구현이다. 정기 일정 표시는 필터 시연이며 반복 계산 완료로 보고하지 않는다.
- 이번 단계는 기존 업무관리툴의 저장 자료를 가져오거나 변경하지 않았다.
