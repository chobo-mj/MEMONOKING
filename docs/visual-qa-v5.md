# v1.7 스티커·독립 창·가독성 검증

검증일: 2026-11-09, 로컬 Windows. 실행 중 UI 프로토타입의 검증이며 영속 저장·제품 전체 인수시험은 아니다.

## 실제 화면·입력으로 확인한 결과

- 공통 벡터 아이콘과 새 탐색 메뉴·색상·여백·버튼 배치를 확인했다.
- 전체 편집창의 완료 체크가 꺼져 있을 때 완료 시간 입력이 보이지 않았다. 체크하면 `완료 시간 :` 라벨과 날짜/시간 선택박스가 나타나고, 체크를 해제하면 함께 사라졌다.
- 완료 시간 달력을 열어둔 상태에서 작업실의 같은 메모 완료 체크를 해제했다. 독립 편집창으로 돌아왔을 때 완료 시간 입력과 달력이 모두 닫힌 것을 확인했다.
- 접기 색상 선택은 긴 텍스트 대신 색이 채워진 견본으로 표시됐다.
- 전체 편집창을 한 번 접으면 제목 한 줄 상태가 됐다. 접기·제목·편집 아이콘만 있으며 별도 펼치기 텍스트나 닫기 버튼은 보이지 않았다.
- 한 줄 제목을 클릭하자 360×360의 색상 스티커가 열렸다. 제목과 본문만 보였고, 일정 등 속성 폼은 없었다.
- 스티커를 321×321로 크기 변경했다. 본문에 한국어 텍스트를 입력하고 창 너비에 맞게 줄바꿈되는 것을 확인했다.
- 스티커 `+`로 두 번째 네이티브 창을 생성했다. 첫 번째 창이 남아 있는 상태에서 새 독립 스티커가 나타났다. 확인한 2520×1440 화면에서 새 360×360 창의 원점은 (1080, 540)으로 중앙이었다.
- 스티커를 접어 색상 네모로 만든 뒤 클릭했을 때 전체 편집창을 거치지 않고 스티커로 복원됐다. 입력한 본문이 유지됐다.
- Chrome이 앞에 있는 상태에서 `Ctrl+Alt+S`를 눌렀을 때 세 번째 메모 뷰포트가 생성됐다. 기존 두 메모 창이 유지됐으며 새 창 제목은 `새 스티커 노트`였다.
- 설정의 ‘스티커 노트 추가’ 입력을 `Ctrl+Alt+S`에서 `Ctrl+Alt+T`로 바꾸고 적용했다. Chrome이 앞에 있는 상태에서 변경한 `Ctrl+Alt+T`를 누르자 새 독립 스티커 창이 생성됐다.

## 구현과 자동 회귀 범위

스티커 창별 원본·표시 모드·발생 날짜·위치/크기를 분리하고, 여러 스티커가 전역 활성 메모 값 때문에 다른 원본을 편집하지 않도록 창 문맥을 복원하는 회귀 범위를 추가했다. 일반 접기 경로와 스티커 선호 경로, 창별 독립 생성/닫기, 선택 발생의 완료 시간 표시, 세 전역 단축키의 중복 조합 거부도 자동 시험 대상이다.

완료 체크를 해제하면 해당 창의 열린 완료 시간 달력을 취소한다. 오래된 완료 시간 입력이 미완료 단일 메모나 기간 발생에 완료 기록을 다시 만들지 않도록 쓰기 시점에도 방어하며, 이 조건과 완료 상태에서의 정상 보정을 회귀시험에 추가했다. 도움말·툴팁의 키 안내는 현재 등록 집합을 기준으로 하고 색상 견본에는 접근성 이름을 추가했다.

`cargo test --locked`: **39개 통과**. `cargo clippy --locked -- -D warnings`와 `cargo build --locked` 통과. 실제 화면 확인과 자동 명령 검증을 구분해 기록하며, 화면에 버튼이 있다는 이유만으로 모든 OS·보안 환경의 동작을 통과했다고 하지 않는다.

## 남은 검증과 현재 범위

- 새 스티커 전역 단축키의 기본값과 사용자 변경값의 외부 호출은 확인했다. OS 점유 충돌·등록 실패·이전 등록 복구 전체 흐름은 아직 UI 인수하지 않았다.
- 도움말·툴팁·접근성 이름은 추가했으나 보조공학 전체 조합과 모든 키보드 이동 경로를 인수하지 않았다.
- 이번 중앙 배치는 한 화면에서 확인했다. 다중 모니터 작업 영역, 여러 배율, 작업표시줄 위치, 화면 밖 창 복구는 추가 검증 대상이다.
- 여러 스티커를 동시에 열고 다른 원본을 편집하는 구조를 추가했으나 대량 창 장시간 운영과 여러 스티커의 IME 조합·포커스 전환 전체 조합은 인수하지 않았다.
- 제목·본문·댓글의 입력 엔진은 현재 다중행 텍스트다. 리치 블록·표·본문 이미지 엔진의 완성을 뜻하지 않는다.
- 메모·스티커·폴더·댓글·프로젝트·창 상태·단축키 변경·이미지 보관 경로는 실행 중에만 유지된다. 앱 종료 후 복구는 미구현이다. 명시적으로 내보낸 이미지 파일만 디스크에 남는다.
- 앱 저장·백업·실제 알림·반복 일정 발생 엔진 등 기존 제품 계획의 남은 기능은 이번 시각 정돈으로 구현 완료 처리하지 않는다.
