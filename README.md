# MEMONOKING

Windows에서 실행하는 Rust + egui/eframe 개인 업무 공간 프로토타입입니다. Notion의 단정한 탐색 구조와 사용자가 제공한 Todoist 화면의 일정 목록을 참고한 독립 디자인입니다.

## 실행

Rust stable과 Windows C++ 빌드 도구 설치 후 `cargo run --release`를 실행합니다. 개발 의존성 다운로드에는 인터넷이 필요합니다. 실행 중 저장·서버 통신은 없습니다. 한국어는 Windows 맑은 고딕을 사용합니다.

## 이번 화면에서 직접 해볼 수 있는 기능

- **내 작업실:** 날짜/시간순 목록, 오른쪽 캘린더 열기·닫기.
- **관리함·오늘·다음:** 시간순 목록, 정기 일정 표시 필터, 프로젝트 필터, 신규 추가·내용/일정 편집·완료.
- **캘린더:** 작은 날짜 숫자와 메모 제목 요약, 목록→날짜 드래그 및 날짜→날짜 이동, 제목 눌러 상세 열기. 월 이동은 실제 연도를 포함합니다.
- **수집함 보드:** 카드 제목을 드래그해 자유 배치. `≡` 손잡이를 다른 카드로 끌면 자식 메모로 종속. 선택 후 관련 선 연결/해제·종속/해제·프로젝트 묶기. 전체/선택/라벨별 보기·중요 별·완료 체크.
- **업무일지:** 완료 메모 내용과 체크 시각 표시. 상세에서 실제 완료 날짜·시간 보정 후 날짜별/월별 조회에 반영.
- **설정:** 다크 모드 및 전역 단축키 변경. 기본 **Ctrl+Alt+N** 빠른 메모, **Ctrl+Alt+C** 분리 캘린더. 앱이 실행 중이면 다른 프로그램에서도 호출합니다. 충돌 시 오류와 복구 결과를 표시합니다.
- 크기 조절 가능한 실제 메모/캘린더 분리창, 표·이미지·즐겨찾기 예시 화면.

## 범위와 남은 작업

모든 변경은 실행 중 메모리에만 존재하며 종료하면 초기화됩니다. 저장·백업·실제 알림·외부 링크 실행·실제 표 붙여넣기·사용자 라벨 생성은 후속 제품 기능입니다. 이미지 화면은 색상 카드 예시입니다.

정기 일정 체크는 **필터용 표시**입니다. 반복 발생 생성과 ‘이번만/이후 모두’ 범위 이동은 계획에 포함되어 있으나 아직 구현하지 않았습니다. 현재 드래그는 화면에 있는 일반 일정의 날짜를 바꿉니다. 드래그는 같은 창 안에서 검증했으며 별도 네이티브 창을 넘나드는 드롭은 지원 범위에 포함하지 않습니다. 보드는 스크롤 캔버스이며 자동 정렬/확대·축소/대규모 가상화는 후속 단계입니다.

`plan.md`와 `plans/`는 장래 제품 계획이며 현재 구현 완료 목록이 아닙니다. 최신 추가 요구는 [15 확장 계획](plans/15-layout-board-journal-shortcuts.md)에 있습니다.

## 검증

`cargo test`의 6개 시험으로 관계 중복·순환 방지·완료 시각·빠른 드래그 입력·잘못된 드롭·카드 이동/일정 분리를 확인합니다. Windows 실제 화면 검증 범위와 한계는 [검증 기록](docs/visual-qa-v2.md)을 참고하세요.
