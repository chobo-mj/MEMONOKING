# MEMONOKING

Windows Rust + egui/eframe 개인 메모·일정 작업 공간 프로토타입입니다. Notion의 탐색 구조와 사용자가 제공한 Todoist 일정 목록을 참고한 독립 디자인입니다.

## 실행

Rust stable과 Windows C++ 빌드 도구를 설치한 뒤 `cargo run --release --locked`를 실행합니다. 빌드 의존성 다운로드에는 인터넷이 필요합니다. 한국어는 Windows 맑은 고딕을 읽습니다.

## v1.7 메모 창과 스티커

- 전체 편집창은 일정·기간·분류를 함께 편집합니다. 완료된 메모/선택 발생에서만 **완료 시간 :** 입력이 나타나고, 체크를 해제하면 열린 완료 시간 선택창도 함께 닫힙니다. 이전 선택창의 입력이 미완료 항목을 다시 완료시키지 않도록 막습니다.
- 접기 색상은 긴 설명 버튼 대신 현재 색을 채운 견본으로 선택합니다. 10개 기본색과 사용자 지정 색상을 제공하며 견본에는 접근성 이름을 붙였습니다.
- 일반 메모의 접기는 **전체 편집 → 제목 한 줄 → 색상 네모** 순서입니다. 제목 한 줄에는 접기·제목·편집 아이콘이 있고 펼치기 텍스트와 닫기 버튼은 없습니다.
- 한 줄 제목을 클릭하거나 전체 편집창의 **스티커 노트** 버튼을 누르면 색상 배경의 스티커가 됩니다. 제목·본문만 보이며 바로 수정할 수 있습니다.
- 스티커는 처음에 정사각형으로 열리고, 모서리로 크기를 바꿀 수 있습니다. 본문은 창 너비에 맞춰 줄바꿈됩니다. 스티커 모드의 접기는 **스티커 ↔ 색상 네모**만 왕복합니다.
- 스티커 우측 상단의 **+**는 화면 중앙에 새 독립 스티커를 만듭니다. 여러 스티커를 동시에 열고 각기 다른 메모를 편집할 수 있습니다. 편집 아이콘은 전체 편집창, 도움말은 조작 설명, 닫기는 해당 창만 닫습니다.
- 기본 전역 키는 **Ctrl+Alt+N** 빠른 메모, **Ctrl+Alt+C** 분리 캘린더, **Ctrl+Alt+S** 새 스티커입니다. 설정에서 직접 입력해 변경하며 앱이 실행 중이어야 합니다. 도움말과 스티커 툴팁은 현재 등록된 키를 안내하고, 아직 적용하지 않은 입력값은 사용 중인 키로 표시하지 않습니다.
- 탐색 메뉴와 창 헤더에 공통 벡터 아이콘, 색상·여백·버튼 배치를 적용했습니다. 아이콘에는 툴팁과 접근성 이름을 제공하고, 닫기 옆에는 문맥 도움말을 둡니다.

상세 계약은 [21 스티커·창·화면 정돈](plans/21-sticker-design.md), 실제 화면 확인 범위는 [v5 검증 기록](docs/visual-qa-v5.md)에 있습니다.

## 메모·일정·위키

- 작업실·오늘·다음의 날짜/시간순 목록, 캘린더 열기/닫기, 목록→날짜와 날짜→날짜 드래그. **프로젝트 없음** 필터에서 빠른 메모를 찾고 일정 없는 메모를 달력에 놓아 일정을 부여합니다.
- 1~5일 기간 일정은 같은 원본 메모를 날짜별로 표시합니다. 완료/해제 시 **이 날짜만 / 이 날짜 이후 모두**를 선택하고, 날짜별 취소선·완료 시각·일지 댓글을 구분합니다. 오늘/다음에는 중요 항목을 위에 추가 표시합니다.
- 수집함의 관계/트리 탭, Ctrl+휠 확대·축소와 팬, 카드 자동정렬, 복수 부모 종속과 순환 방지, 관련 선, 프로젝트 묶기. `≡` 손잡이는 종속 드롭, 제목은 카드 이동입니다.
- 위키의 **새 폴더**는 선택 없음이면 최상위, 선택 폴더가 있으면 그 안에 생성합니다. 폴더와 메모를 드래그해 분류하고 미분류 메모만 볼 수 있습니다.
- 위키 오른쪽 목록 클릭은 독립 편집창을 엽니다. 왼쪽 트리 제목 클릭은 오른쪽 본문/댓글 보기로 전환하며, 트리에서도 댓글을 펼칠 수 있습니다. 완료·과거 일정과 무관하게 위키 표시를 유지합니다.
- 프로젝트 관리에서 생성·숨김·재활성화·삭제 범위를 선택합니다. 첫 줄 `#프로젝트명` Enter로 프로젝트를 지정/생성합니다.
- 생성시각 기록·표시·정렬, 제목+본문 검색, 생성일/일정/프로젝트/첨부/숨김 상세 조건을 지원합니다. 결과 날짜를 누르면 우측 달력이 해당 월로 이동합니다.
- 날짜 필터는 시작/끝을 사용합니다. 시작일을 고르면 둘 다 같은 날로 설정하고, 더 이른 종료일을 고르면 자동으로 순서를 정리합니다.

## 편의기능

- 업무일지·표·이미지·링크/즐겨찾기는 중앙 탭으로 묶었습니다. 일지는 일/월 조회와 달력 날짜 선택, 댓글 개별/전체 펼치기·숨기기를 제공합니다.
- 본문과 모든 댓글은 동일한 다중행 텍스트 입력 위젯을 사용합니다.
- 예시 표의 셀 내용을 검색하고 HTML table/TSV 또는 PNG 이미지로 실제 클립보드에 복사합니다.
- 갤러리에서 날짜/기간과 이미지 용량을 확인합니다. 이미지 클릭은 복사, 저장 아이콘은 다른 이름 저장입니다. 일괄 저장과 백업 검증 후 원본 용량 정리, 썸네일·백업 찾기를 제공합니다.
- Chrome/Edge의 UTF-8 즐겨찾기 HTML을 가져옵니다. http/https 링크만 반입하며 링크는 기본 브라우저로 엽니다.

## 현재 범위

**앱 데이터는 종료하면 초기화**됩니다. 메모·스티커·폴더·댓글·프로젝트·창 설정·단축키 변경·이미지 보관 경로를 영구 저장하지 않습니다. 사용자가 명시적으로 저장한 이미지 파일은 디스크에 남습니다.

앱 저장·백업·실제 알림·반복 발생 계산과 ‘이번만/이후 모두’ 시리즈 이동은 후속 단계입니다. 현재 기간 일정의 날짜별 완료와 실제 반복 일정 엔진을 구별합니다.

본문/댓글은 현재 텍스트 기반이며 리치 블록·표 붙여넣기·본문 이미지 편집 엔진은 아직 연결하지 않았습니다. 표/이미지 모아보기는 예시 데이터 기반입니다. 즐겨찾기는 링크 목록을 가져오며 HTML 폴더 구조 재현은 후속 단계입니다. 보안 락이 걸린 PDF/PPT/Excel을 읽거나 잠금을 우회하지 않습니다.

이미지 64 MB/8192×8192, HTML 10 MB 입력 제한은 개발 중 한계이며 제품 제한의 확정 값이 아닙니다. 숨김은 화면 가시성 기능이며 보안 권한 기능이 아닙니다.

## 계획과 검증

제품 계획 v1.7은 [plan.md](plan.md)와 `plans/`에 있습니다. 계획은 현재 UI의 구현 완료 목록이 아닙니다.
