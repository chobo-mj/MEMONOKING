# MEMONOKING

Windows Rust + egui/eframe 개인 메모·일정 작업 공간의 **화면·조작 프로토타입**입니다. 사용자 PPT 15장과 최신 프로젝트/아이콘 도구 요청을 반영합니다.

## 실행

Rust stable과 Windows C++ 빌드 도구를 설치한 뒤 `cargo run --release --locked`를 실행합니다. 빌드 의존성 다운로드에는 인터넷이 필요합니다. 설치된 Windows 글꼴을 사용하며 없는 글꼴은 기본 글꼴로 표시합니다.

## v1.8 동작

- 메모 분류는 **프로젝트 / 프로젝트 없음**만 사용합니다. 개인·프로젝트·회의 고정 분류와 라벨 모델·필터를 제거했습니다. 메모 색상, 위키 폴더, 전체메모 정리 폴더와 메모 관계는 유지합니다.
- 스티커 좌상단 `+`, 우상단 압정·완료·접기·닫기와 더보기 메뉴를 제공합니다. 상단 물음표는 제거하고 도움말은 더보기에서 엽니다. 본문 도구는 아이콘으로 표시하며 선택형 도구는 작은 팝업을 엽니다.
- 접기는 **스티커 → 제목 한 줄 → 색상 상자** 순서입니다. 설정에서 제목 단계를 건너뛸 수 있습니다. 제목줄은 가로폭을 바꾸고 상자는 드래그 이동·모서리 크기 변경·Shift 정사각형·더블클릭 복원을 지원합니다.
- 제목이 비어 있으면 본문의 첫 유효 줄을 제목으로 사용합니다. 첫 줄 `#프로젝트명 + Space`는 프로젝트를 생성/지정합니다. 본문 탭은 독립 내용을 가지며 제목·프로젝트·일정은 함께 사용합니다.
- 본문/댓글에 선택 범위 서식, 글꼴·크기, 자동 순번·2칸 들여쓰기, 체크박스, 취소선 입력, 날짜 키, 링크, 편집 가능한 표와 이미지 블록을 제공합니다. 탭 추가·이름 변경·숨김·복원·삭제 휴지통, 본문 Ctrl+휠 30~200% 배율을 지원합니다.
- 표는 TSV 붙여넣기와 셀·행·열 편집, 이미지는 파일/클립보드/드롭 및 비율 유지 배율을 지원합니다. 실제 삽입한 표·이미지는 모아보기와 원본 탭 이동에 연결됩니다. 표는 HTML/TSV 또는 PNG 복사, 이미지는 클릭 복사·PNG 저장·일괄 저장을 제공합니다.
- 달력을 닫은 작업실은 상세 목록과 우측 편집 미리보기로 바뀝니다. 방향키 선택, 완료·스티커 표시·알람 날짜 선택·일정 수정·삭제 동작을 제공합니다.
- **전체메모**의 폴더 보기/전체 메모 보기/관계 보드에서 정리합니다. 폴더 생성·이름 변경·드래그, 단일/복수 메모 분류, 프로젝트·생성일·일정·정기·위키 필터와 모든 본문 탭의 이전/다음 찾기·범위별 바꾸기를 제공합니다.
- 편의기능에는 업무일지·표·이미지·링크/즐겨찾기·휴지통이 있습니다. 삭제된 메모와 본문 탭을 구분해 복원하고 영구삭제 전 확인합니다.
- 달력은 작성일/일정/알람 기준, 월 이동·오늘·날짜 호버의 새 스티커와 날짜 간 드래그를 제공합니다. 작성일은 일정을 드래그해도 바뀌지 않습니다.
- 설정은 일반/메인창/메모창/알람/단축키/백업·복원/정보로 나눕니다. 기본 전역 키는 Ctrl+Alt+N(빠른 메모), Ctrl+Alt+C(분리 캘린더), Ctrl+Alt+S(새 스티커)이며 사용자 변경을 지원합니다.

## 현재 범위와 한계

**종료하면 메모와 설정이 초기화됩니다.** 저장·백업/복원·암호화·실제 Windows 알림/트레이/자동시작·기간 자동삭제는 후속 기능입니다. 해당 설정은 선택과 미리보기까지 연결했습니다. 잠금은 비밀번호를 입력해 화면을 가리고 다시 여는 시뮬레이션이며 실제 암호화 보안을 제공하지 않습니다.

투명도는 배경색으로 미리 봅니다. 자간은 설정값 선택 단계이며 전체 위젯의 글자 배치는 후속 연결입니다. 표·이미지는 해당 본문 탭의 아래쪽 블록으로 배치하며 문장 중간의 완전한 리치 블록 배치와 다중 셀 선택/병합은 후속입니다. 설치되지 않은 글꼴을 임의로 다운로드하지 않습니다.

정기 일정의 실제 발생 계산과 ‘이번만/이후 모두’ 시리즈 이동, 완전한 오프라인 한국 공휴일 데이터 팩도 후속입니다. 현재 달력은 주말과 고정 양력 공휴일의 표시 예시이며, 음력·대체·임시 공휴일의 완전한 표시를 보장하지 않습니다.

명시적 이미지 내보내기 파일만 디스크에 남습니다. 이미지 64 MB/8192×8192, HTML 10 MB 반입 제한은 개발 중 한계입니다. 즐겨찾기는 Chrome/Edge HTML에서 http/https 링크를 가져오며 HTML 폴더 재현은 후속입니다. 보안 락이 걸린 PDF/PPT/Excel을 읽거나 잠금을 우회하지 않습니다.
