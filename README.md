# MEMONOKING

Windows Rust + egui/eframe 개인 메모·일정 작업 공간 프로토타입. Notion의 탐색 구조와 사용자가 제공한 Todoist 일정 목록을 참고한 독립 디자인입니다.

## 실행

Rust stable, Windows C++ 빌드 도구를 설치한 뒤 `cargo run --release --locked`. 빌드 의존성 다운로드에는 인터넷이 필요합니다. 한국어는 Windows 맑은 고딕을 읽습니다.

## 화면에서 해볼 수 있는 기능

- 작업실·오늘·다음의 일정순 목록, 오른쪽 캘린더 열기/닫기, 목록→날짜와 날짜→날짜 드래그.
- **메모 편집은 독립 창**. 접기 버튼: 전체→제목 한 줄→색상 네모. 네모 클릭 시 전체 복원. 항상 위에, 10개 색상과 사용자 지정 색상, 날짜·시간 달력 입력.
- **수집함** 관계/트리 탭, Ctrl+휠 확대·축소와 팬·카드 자동정렬, 여러 부모 종속(순환 차단), 관련 선, 프로젝트 묶기. `≡` 손잡이는 종속 드롭, 제목은 카드 이동.
- **나만의 위키** 체크한 메모를 독립 폴더 트리로 분류. 완료/과거 일정과 무관하게 제목·본문을 읽고 위키 전용 댓글 작성.
- **편의기능** 안의 업무일지/표/이미지/즐겨찾기 탭. 일지 댓글 개별·전체 펼치기/숨기기. 완료 시각 수정과 일/월 조회.
- 표 셀 내용 검색, HTML table/TSV 또는 PNG 이미지로 실제 클립보드 복사.
- 갤러리 날짜/기간 필터와 총 용량 표시. 이미지 실제 복사·다른 이름 저장·일괄 저장. 보관 파일 검증 후 본문 용량 비우기, 기억 경로에서 임시 다시 보기.
- Chrome/Edge 내보내기 UTF-8 HTML 즐겨찾기 가져오기. http/https 링크만 반입하고 링크는 기본 브라우저에서 열기.
- 프로젝트 관리의 생성/숨김/활성화/삭제 범위 선택. 첫 줄 `#프로젝트명` Enter로 프로젝트 지정/생성.
- 생성시각 기록·표시·정렬. 제목+본문 검색과 생성일/일정/프로젝트/첨부/숨김 상세 조건. 결과 날짜 클릭 시 우측 달력을 해당 월로 이동.
- 전역 단축키 설정. 기본 Ctrl+Alt+N 빠른 메모, Ctrl+Alt+C 분리 캘린더.

## 현재 범위

**앱 데이터는 종료하면 초기화**됩니다. 폴더·댓글·프로젝트·보관 이미지 경로도 영구 저장하지 않습니다. 사용자가 명시적으로 저장한 이미지 파일은 디스크에 남습니다. 앱 저장·백업·실제 알림·반복 발생 계산과 ‘이번만/이후 모두’ 이동은 후속 단계입니다.

표/이미지 모아보기는 예시 데이터 기반이며 실제 본문 첨부 편집 엔진은 아직 연결하지 않았습니다. 반입 즐겨찾기는 링크 목록이며 HTML 폴더 구조 재현은 후속 단계입니다. 보안 락이 걸린 PDF/PPT/Excel을 읽거나 잠금을 우회하지 않습니다. 일반 편집창은 현재 활성 메모 하나입니다.

파일 입력은 이미지 64 MB/8192×8192, HTML 10 MB 개발 제한을 적용했습니다. 이는 제품 제한의 확정 값이 아닙니다. 숨김은 UI 가시성 기능이며 보안 권한 기능이 아닙니다.
