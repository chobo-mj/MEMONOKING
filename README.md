# MEMONOKING

Rust + egui/eframe로 만든 Windows 개인 업무 공간 UI 프로토타입입니다. Notion의 여백·밝은 종이·왼쪽 탐색 구조를 참고한 독립 디자인이며 공식 Notion 제품이 아닙니다.

## 실행

Rust stable 및 Windows C++ 빌드 도구 설치 후 `cargo run --release`를 실행하세요. 개발 의존성 다운로드에는 인터넷이 필요합니다. 실행 중 데이터 통신·저장 기능은 없습니다. 한국어 글꼴은 Windows의 맑은 고딕을 읽습니다.

## 시연 기능

- 사이드바 탐색/접기·메모 제목 검색·메모 생성/편집·체크박스
- 크기 조절 가능한 실제 메모/캘린더 분리창과 닫기·다시 열기
- 좌우 분할·월 이동·날짜 선택·빠른 입력·라벨 선택·설정/다크 모드
- 표·이미지 카드·즐겨찾기·업무일지 예시 화면

모든 변경은 실행 중 메모리에만 있습니다. 파일 저장·데이터 연결·백업·실제 알림·외부 링크 실행·정기 일정 계산은 구현하지 않았습니다. 이미지 영역은 색상 카드 예시입니다. 캘린더 주/일 선택은 시각적 모드 시연입니다.

`plan.md`와 `plans/`는 장래 제품의 상세 요구사항이며 이 UI의 구현 완료 목록이 아닙니다.

GitHub Actions의 Windows 빌드에 더해, 2026-11-08 로컬 Windows에서 실제 실행하여 한글 빠른 입력, 화면 전환, 좌우 분할, 분리창과 스크롤, 밝은/어두운 테마를 확인했습니다. 상세 범위와 한계는 [시각 검증 기록](docs/visual-qa.md)을 참고하세요.
