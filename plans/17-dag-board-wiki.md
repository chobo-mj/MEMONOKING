## 데이터 계약

- `NoteParentEdge(parent_note_id,child_note_id,created_at)`, 복합 고유키. `RelatedNote(min_id,max_id)`와 별도.
- Edge 추가 전 child에서 parent로 이어지는 하위 경로가 있으면 거부한다. 구현상 parent의 조상 집합에 child가 있는지 역탐색해도 동일하다. 모든 부모 경로를 탐색하며 첫 부모만 검사하지 않는다. DB 트랜잭션/동시 명령 직렬화로 경쟁 순환을 막는다.
- 삭제 명령을 `RemoveParentEdge`와 `DeleteNote`로 구분한다. 부모 연결 해제는 다른 부모/메모/댓글을 지우지 않는다. 여러 선택의 종속 추가는 원자 처리 또는 부분 성공 범위를 명시한다.
- `WikiFolder(id,parent_folder_id,title,description,sort_key)`는 메모가 아니다. 메모는 `is_wiki`, `wiki_folder_id`를 가진다. 기본은 폴더 하나+미분류이며 복수 위키 폴더 배치가 필요한지는 별도 결정 기록으로 남긴다. 위키 표시 해제 시 댓글은 삭제하지 않고 다시 체크하면 복원한다.
- `WikiComment(id,note_id,body,created_at,edited_at?)`는 위키 전용. 일반 메모 검색의 본문에 무조건 합치지 않는다.

## 트리와 보드 투영

DAG는 엄밀한 단일 트리가 아니므로 경로별 메모 참조를 펼쳐 표시한다. 공통 자식은 여러 경로에 나타나며 같은 원본임을 표시한다. 관련 연결만 있는 메모는 종속으로 바꾸지 않는다. 트리보기에서는 관련 메모 참조 그룹/하위 표식을 별도로 제공하고 무방향 연결의 왕복 순환을 방문 경로 집합으로 차단한다. 부모가 숨겨졌거나 삭제돼도 접근 가능한 자식이 트리에서 사라지지 않도록 별도 루트로 투영한다.

자동정렬은 ID에 대응하는 카드 좌표만 갱신한다. 그리드 기본 및 계층 배치 선택을 제품 단계에서 검토한다. 큰 보드의 가상화·공간 인덱스·선 겹침 완화와 확대/축소 최소/최대치는 실측 후 결정한다. 논리적 중첩 깊이는 제한하지 않되 화면은 지연 로딩하고 스택 재귀 폭발을 피한다.

## 위키 화면과 폴더 동작

중앙 트리에 폴더 제목·설명을 표시하고 펼치면 메모 제목 목록을 보여준다. 우측은 읽기용 제목·본문과 하단 댓글이다. 편집/완료 조작은 별도 일반 편집창에서 한다. 폴더 추가는 최상위 또는 선택 폴더 하위. 폴더 이동도 순환 검사한다. 폴더 삭제 기본은 메모를 미분류로 보존하며 하위 폴더 유지/승격 정책을 명시한다. 이번 사용자 요청에는 폴더 삭제 UI를 필수로 포함하지 않았으므로 구현 전 정책을 정하고 확장한다.

## 마이그레이션

기존 `Note.parent_id`를 `NoteParentEdge` 한 행으로 변환하고 무결성/개수/순환 검사 후 기존 필드 제거. 기존 관련 선은 그대로 보존. 모든 기존 메모의 위키 플래그는 false, 폴더는 비어 있음으로 초기화하며 임의 자동 분류하지 않는다. 위키 폴더/댓글·보드 좌표는 백업/복원에 포함한다. 실패 시 이전 스키마 스냅샷으로 되돌린다.
