## 모델과 상태기계

`MemoWindowState(note_id, mode: Full|Title|Swatch, full_bounds, compact_position, always_on_top, swatch_rgba)`는 본문과 분리된 창/표시 설정이다. 색상은 라벨과 독립이다. 원본 메모 하나를 같은 ID로 참조하고 창마다 본문 복사본을 만들지 않는다.

모드 전이는 영속 저장과 별개의 UI 명령. Full을 떠나기 전에 현재 편집/IME 조합을 안전하게 확정 또는 취소하고 마지막 Full 크기를 기록한다. Title·Swatch는 최소 크기 제약을 함께 바꿔 장식 없는 창이 불필요한 빈 공간을 차지하지 않게 한다. 네모 클릭과 드래그를 구별하며 제목/네모의 접근성 이름과 복원 대체 명령을 제공한다. 창 닫기는 삭제가 아니다. 여러 메모 창은 note_id별 상태·포커스를 분리한다. 프로토타입의 활성 메모 창은 하나이며 여러 창 동시 편집은 제품 단계 검증 대상이다.

날짜 선택기는 호출 창/입력 필드를 소유자로 가진다. 루트 상세 검색을 열었는데 별도 메모 창 안에 달력이 나타나지 않아야 한다. `Picker(owner_window_id,target_field,selected_date,hour,minute)`의 적용은 유효성 검사 후 하나의 명령으로 원본에 반영한다. 취소/닫기는 무변경. 시간대는 02/04의 로컬 시간 정책을 따른다.

## 시험

- M16-T-01: Full→Title→Swatch→Full→Title 반복 30회, 현재 제목·본문·색·마지막 Full 크기 보존.
- M16-T-02: 최소/최대 크기, 100/150/200% 배율, 다른 모니터로 이동 후 작은 네모가 화면 밖으로 사라지지 않음.
- M16-T-03: 위에 고정/해제 후 다른 프로그램 창과 순서 비교. OS 포커스 제한 실패는 버튼·작업표시줄 대안으로 처리.
- M16-T-04: 10색 및 임의 RGB/알파 선택, 잘못된 값·대비·색각 보조 표시. 라벨 변경과 접기 색상이 독립.
- M16-T-05: 윤년·월말·연말·23:59, 날짜만/시간만/완료 시각 보정, 두 창의 선택기 소유자 분리.
- M16-T-06: IME 조합 중 접기·닫기·복원, 초안 유실/중복 입력 없음.

예상 버그: 네이티브 최소 크기 때문에 작은 네모가 커짐, 장식 높이와 클라이언트 높이 혼동, 복원 시 작은 창 크기로 Full 크기 덮어쓰기, 항상 위에 설정 해제 누락, 모달 달력이 다른 창에 나타남. 창 명령 순서·모드별 크기 캐시·소유자 ID로 방지한다.

## 개발 순서

현행 창 프레임워크와 보안 정책 조사 → 단일 활성 메모 상태 시연 → 여러 메모 창 수명주기 연결 → 창 설정 저장/복구 마이그레이션 → 실제 사내 PC의 배율·포커스·IME 인수. 기존 창 데이터에 mode=Full, always_on_top=false, 기본 색을 부여하며 본문을 변환하지 않는다.
