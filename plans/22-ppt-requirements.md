# 22. PPT 15장 반영 계약 — 스티커·설정·본문·전체메모

v1.8 · 2026-11-10 · 상태: **구현 계약, 실행 검증 대기**

사용자가 제공한 PPT 15장을 화면·조작의 최신 기준으로 적용한다. 슬라이드별 추적표는 [PPT 요구 추적](../docs/ppt-requirements-v18.md)에 둔다. 원본 PPT와 추출 이미지는 저장소에 넣지 않는다. 이 문서는 기능 완료 보고가 아니며, 화면에 옵션이 있다는 이유만으로 저장·암호화·Windows 연동이 구현되었다고 표현하지 않는다.

## 1. 우선순위와 이번 작업 범위

사용자 추가 답변에 따라 이번 단계는 **UI와 조작 우선**이다. 같은 실행 세션에서 상태가 일관되게 바뀌고, 메모·탭·폴더·창의 조작 결과를 확인할 수 있게 한다. 실제 영구 저장, 데이터 위치 전환·가져오기, 자동 백업·복원, 이미지 자동 정리, 비밀번호 암호화, Windows 알림센터·트레이·자동실행 연동은 후속이다. 해당 설정은 명확한 미리보기/후속 안내를 제공하고 실제 OS나 파일을 변경한 것처럼 성공 표시하지 않는다. 기존 명시적 이미지 내보내기·클립보드 등 실제 기능은 별도 검증 결과를 따른다.

충돌 해결 순서는 최신 사용자 답변 → PPT → 21 → 20 → 이전 모듈이다. 과거 문서의 역사적 계약은 남겨 두되 다음 변경은 이 문서가 우선한다.

| 충돌 지점 | v1.8 적용 계약 |
|---|---|
| 스티커는 네모와 바로 왕복 | 기본은 스티커 → 제목 한 줄 → 색상 상자. 설정으로 제목 단계를 건너뛸 수 있음 |
| 색상 상자 단순 클릭 복원 | **더블클릭**으로 펼친 스티커 복원. 단순 클릭·이동·크기 변경으로 복원하지 않음 |
| 상자는 항상 정사각형 | 자유로운 직사각형 크기 변경, Shift를 누른 크기 변경에서 정사각형 유지 |
| 스티커 + 버튼 우측 배치 | 새 스티커 +는 좌측 상단. 압정·완료·접기 등 상태 조작은 우측 상단 |
| 본문 단일 편집 영역 | 제목·프로젝트·일정·완료를 공유하는 복수 본문 탭 |
| 수집함 보드가 대표 진입 메뉴 | 대표 이름은 **전체메모**, 폴더 보기/전체 메모보기 탭. 관계·트리 기능은 별도 접근을 보존 |
| #프로젝트명 Enter | 첫 본문 줄의 #프로젝트명 뒤 **Space**로 지정/생성. 기존 Enter는 호환 조작으로 유지 가능하나 Space 누락은 불가 |
| 실제 비밀번호 보호 추정 | UI 잠금 시뮬레이션. 메모리·디스크·프로세스 접근을 보호하는 보안 통제로 안내 금지 |

기존 요구 중 완료 시각의 조건부 노출·기간 발생별 완료, 댓글, DAG 순환 방지, 위키, 날짜 범위 정규화, 달력 드래그, 프로젝트 없음 필터는 유지한다. PPT에 없다는 이유로 제거하지 않는다. 메모별 변경 이력 열람 UI는 계속 제외한다.

## 2. 슬라이드별 요구 등록과 수용기준

요구 ID는 `P18-S01`~`P18-S15`, 하위 요구는 `.1` 등으로 표기한다. 아래 수용기준은 이번 UI 단계와 후속 제품 단계의 경계를 함께 명시한다.

### P18-S01 — 스티커 기본 모양과 제목 추출

둥근 모서리와 색상 배경을 사용한다. 좌측 상단 +로 새 독립 스티커를 생성한다. 우측 상단에 압정·완료 체크·접기를 배치하고 압정 해제는 흐린 상태로 표현한다. 각 아이콘에는 툴팁·접근성 이름·키보드 초점을 제공한다.

제목이 비어 있고 본문만 입력되면 첫 유효 텍스트 줄을 제목으로, 이후 줄을 본문으로 읽는다. 첫 줄이 프로젝트 생성 명령이면 명령을 처리하고 다음 유효 줄을 제목 후보로 사용한다. 이미 제목이 있으면 본문을 입력할 때마다 제목을 덮어쓰지 않는다. 한글 IME 조합 중·붙여넣기 중간에는 줄을 이동하지 않고 입력 확정/편집 종료 시 단일 명령으로 처리한다. 프로젝트 명령만 있고 내용이 없으면 제목 없는 새 메모 상태를 유지한다.

수용: 서로 다른 스티커 3개에서 제목 추출·프로젝트·완료·압정이 각 원본에만 반영된다. +는 기존 본문·탭·창 위치를 바꾸지 않는다. 완료 시각은 선택 메모/발생이 완료일 때만 `완료 시간 :`와 함께 표시한다.

### P18-S02 — 편집 도구와 하단 툴바

입력 중 더보기·알람·팔레트·압정·접기·닫기를 제공한다. 상단의 항상 보이는 상태 조작과 편집 시 확장되는 보조 도구가 중복 실행되지 않도록 구분한다. 하단은 본문과 선/여백으로 구분하고 글꼴·굵게·기울임·밑줄·취소선·크기·메모 투명도 및 본문 탭을 배치한다. 설정의 자동 숨기기를 끄면 비편집 상태에도 도구가 보인다.

수용: 작은 창에서 도구가 본문을 덮거나 화면 밖으로 사라지지 않고 메뉴/스크롤로 접근된다. 도구 클릭으로 편집 선택영역을 잃지 않는다. 시각 서식이 아직 실제 본문 모델에 연결되지 않은 경우 UI 미리보기로 구별하고 리치 편집 완료로 보고하지 않는다.

### P18-S03 — 본문 탭

각 탭은 독립 `body`를 갖고 메모의 제목·프로젝트·일정·완료·알람은 공유한다. +는 빈 탭을 추가하며 기존 탭의 본문을 덮어쓰지 않는다. 탭 이름 변경, 우클릭 숨기기/보이기, 삭제를 제공한다. 숨김은 삭제가 아니며 숨긴 탭 관리에서 다시 표시한다. 마지막 표시 탭을 숨겨도 복구 진입점은 남는다. 모든 탭을 삭제한 메모는 빈 작성 영역을 제공한다.

폭을 넘으면 좌/우 화살표로 탭을 스크롤하고 현재 탭을 보이게 한다. 탭 삭제는 휴지통에 `메모제목-탭제목`과 그 본문을 별도 항목으로 넣는다. 탭 삭제로 메모·다른 탭·일정을 삭제하지 않는다. 수용: 탭 전환 20회·이름 변경·숨김 복원·삭제 취소에도 각 본문·ID·순서가 보존된다.

### P18-S04 — 더보기와 메모 잠금 UI

더보기에서 도움말, 개별 잠금, 위키 체크, 프로젝트 하위 메뉴, 동일 프로젝트 보기, 복제, 휴지통 이동, 영구삭제, 스티커 설정에 접근한다. 프로젝트 하위 메뉴는 포인터 이동 중 닫히지 않고 클릭·키보드로도 선택할 수 있다. 동일 프로젝트 보기는 작업실 필터를 설정한다. 프로젝트 없는 메모는 프로젝트 없음 필터를 사용한다.

잠금 시 비밀번호 입력/해제 흐름을 시뮬레이션한다. 잠긴 메모는 자물쇠가 있는 상자로 표시하고 크기 변경을 금지하며 스티커 표시를 해제할 수 있다. 작업실에서는 제목만 표시하고 본문·미리보기·편집을 숨긴다. 동일 원본의 모든 열린 창에 적용한다. 제목 검색 외에 본문 검색 미리보기·전체메모·위키·일지 등 우회 노출도 검토한다. **이것은 화면 가림 시뮬레이션이며 암호화·접근 통제가 아니다. 실제 민감정보 보호에 사용하지 않는다.**

복제는 새 메모 ID와 새 탭 ID를 생성한다. 잠긴 원본은 해제 전에 복제해 본문을 노출하지 않는다. 휴지통/영구삭제는 대상·차이를 명시하고 영구삭제는 별도 확인한다. 취소 시 아무 변경도 없다. 휴지통 이동 후 모든 관련 창이 닫히거나 삭제 상태로 일관되게 바뀐다.

### P18-S05 — 스티커 설정

설정 항목은 새 스티커 기본색, 툴바 자동 숨기기(기본 켬), 기본 글꼴(맑은 고딕), 기본 글자 크기(10), 접기 1단계 건너뛰기(기본 끔), 기본 투명도, 상자 최소화 시 항상 위 자동 해제(기본 켬), 이미지 붙여넣기 배율(25/50/75/100%/너비맞춤, 기본 100%)이다. 기존 10색 빠른 선택 및 별도 사용자 지정 색상은 유지한다. 기본값 변경은 이후 새 메모의 기본값이며 기존 메모의 개별 설정을 조용히 덮어쓰지 않는다.

수용: 기본값과 현재 메모 설정이 구별되고 선택 결과가 실행 세션에서 반영된다. 투명도를 낮춰도 조작이 가능한 최소 대비·복원 경로를 제공한다. 배율은 이미지 종횡비를 바꾸지 않는다. 현재 본문 이미지 엔진 미연결 항목은 미리보기로 표시한다.

### P18-S06 — 접기·이동·크기 변경

기본 상태 전이는 아래 표를 따른다. 일반 전체 편집폼은 속성 편집용 별도 진입이며 상자 복원 경로에 강제로 끼우지 않는다.

| 시작 | 조작 | 결과 |
|---|---|---|
| Sticker | 접기, 건너뛰기 끔 | TitleLine, 마지막 스티커 본문/크기 보존 |
| Sticker | 접기, 건너뛰기 켬 | ColorBox |
| TitleLine | 접기 | ColorBox |
| TitleLine | 제목/편집 진입 | 같은 원본 Sticker 또는 명시한 전체 편집 진입 |
| ColorBox | 더블클릭 | 기억한 펼친 Sticker 크기로 복원 |
| ColorBox | 단순 클릭/드래그 | 선택 또는 이동, 복원하지 않음 |
| ColorBox | 모서리 드래그 | 자유 크기 변경; Shift 중 정사각형 |
| LockedBox | 크기 변경/복원 시도 | 크기 유지, 해제 대화상자; 원문 노출 없음 |

제목 한 줄은 모서리로 가로 폭만 바꿀 수 있고 드래그로 이동한다. 포인터를 올리면 왼쪽 접기, 오른쪽 압정이 보인다. 색상 상자는 위치 이동·모서리 크기 변경이 가능하다. 기본 설정에서는 상자가 될 때 항상 위를 해제하며, 자동 해제 옵션을 끈 경우 현재 값을 유지한다. 복원 시 이전 압정 상태를 되돌릴지 여부는 명시적 정책으로 통일하고 UI 설명과 실제 동작을 맞춘다(기본안: 자동 해제 후에는 해제 상태 유지).

클릭/더블클릭/이동/크기 변경은 포인터 임계값으로 분리한다. 드래그 종료가 더블클릭으로 처리되어 갑자기 펼쳐지지 않는다. 모드별 위치·크기를 메모 창별로 기억하며 다른 메모의 전환에 전파하지 않는다.

### P18-S07 — 달력을 닫은 작업실 상세 보기

상세 행은 스티커 표시 눈 아이콘, 완료 체크, 제목, 본문 요약, 알람(mm/dd hh:mm), 생성일(yymmdd), 일정(mm/dd hh), 삭제를 구별한다. 제목·본문·일정은 편집 진입, 알람은 알람 설정 진입이다. 우측에는 선택 메모를 제목·본문 수정 가능한 스티커 형태로 표시한다. 위/아래 키로 목록 선택을 옮기되 본문 입력 중 커서 이동을 가로채지 않는다. 선택된 행을 가상 목록 안으로 스크롤한다.

수용: 일정 없는 메모와 날짜 없는 알람은 명확히 빈 상태로 표시하고 거짓 날짜를 만들지 않는다. 잠긴 메모는 제목 외 내용을 노출하지 않는다. 같은 원본의 우측 미리보기와 분리창이 일치한다.

### P18-S08 — 일반 설정

Windows 시작 시 자동실행, 메모창 작업표시줄 표시(끔이면 트레이), 휴지통 보관기간 7/30/90/365일/자동삭제 안함, 잠긴 메모 자동 재잠금 1/5/15분/Windows 잠금 때만을 제공한다. 이번에는 선택값·미리보기만 다루며 레지스트리·작업 스케줄러·실제 트레이·자동 삭제·Windows 세션 감시는 실행하지 않는다. 마지막 창을 닫아도 알림이 유지되는 제품 동작은 실제 상주 단계에서 검증한다.

### P18-S09 — 메인창 설정

라이트/다크, 글꼴(맑은 고딕·굴림·돋움·바탕·궁서체·개구쟁이), 크기(기본 10), 자간(-0.5/기본/+0.5/+1.0), 목록 행 간격(좁게/기본/넓게, 기본은 기본)을 제공한다. 설치되지 않은 글꼴은 대체 글꼴과 미지원 안내를 사용한다. 자간 값을 선택할 수 있다는 이유로 실제 렌더링 지원을 완료 처리하지 않는다.

작업실 옵션은 달력 함께 보기 시 본문 한 줄(기본 끔), 잠긴 메모 숨기기(기본 끔), 완료 메모 숨기기(기본 켬)이다. 숨김은 삭제가 아니다. 숨기기 후 선택 메모가 없어지면 우측 편집 대상도 안전하게 갱신한다.

### P18-S10 — 알람 설정

소리는 Windows 기본/소리 없음(기본 Windows 기본), 우측 하단 팝업(기본 켬), 전체 알림 끄기(기본 끔)를 제공한다. 이번 UI 단계는 미리보기이며 실제 알림센터·트레이 상주·소리를 구현했다고 표현하지 않는다. 제품 단계에서는 Windows 알림센터, 해당 메모 표시·테두리 강조, 모든 창을 닫아도 트레이에서 알림을 유지한다.

PPT의 ‘전체 알림 끄기 on 시 재설정’은 원래 시각/반복 규칙을 삭제하지 않고 **전달을 일시 중지**하는 기본안으로 해석한다. 다시 켰을 때 지난 알림을 어떻게 요약할지는 04의 누락 알림 정책과 결정한다. 실행 증거 없이 기존 알림의 삭제/재생성을 하지 않는다.

### P18-S11 — 전역·앱·본문 단축키

전역 동작 세 개(빠른 메모/분리 캘린더/새 스티커)는 기존 사용자 지정·충돌 감지·등록 실패 복구 계약을 유지한다. 아래 앱 내부 단축키는 편집/선택 문맥에서만 실행하고 Windows 전체 입력 후킹으로 구현하지 않는다.

| 조합 | 계약 |
|---|---|
| Ctrl+Shift+H | 모든 스티커 창 닫기; 원본 삭제·작성 내용 폐기 아님 |
| Ctrl+T | 현재 편집/선택 메모의 항상 위 토글 |
| Ctrl+B / I / U | 편집 선택영역/입력 서식 굵게/기울임/밑줄 |
| ~~ + Space | 직전 한 단어 취소선, 이후 입력에는 전파하지 않음 |
| ~~~ + Space | 현재 줄 취소선, 줄바꿈 다음 입력에는 전파하지 않음 |
| 취소선 위치에서 Backspace | 우선 서식 해제; 문자를 의도치 않게 함께 삭제하지 않음 |
| [] + Space | 인라인 체크박스 삽입, 문장 중간도 지원 |
| Ctrl+; / Ctrl+Shift+; | yy-mm-dd / yy-mm-dd hh:mm:ss 삽입 |
| Ctrl+F / Ctrl+H | 빠른 검색 / 찾아 바꾸기 |
| Ctrl+P | 프로젝트 선택 팝업, 선택 시 보기 필터 적용 |
| 첫 본문 줄 #TEXT + Space | TEXT 프로젝트 지정/없으면 생성, 명령 부분은 본문 내용과 구별 |
| Esc 두 번 | 현재 메모 창 닫기; 첫 Esc는 열린 팝업/입력 조합 취소 우선 |

찾아 바꾸기는 현재 메모/선택 프로젝트/전체 메모 범위를 제공한다. 숨김·잠금·휴지통·숨긴 탭의 포함 여부와 대상 수를 실행 전에 보여주고 기본은 잠금/휴지통 제외다. 다중 원본 변경은 원자 명령과 실행취소를 전제로 하며 미연결이면 시뮬레이션/미리보기로 안내한다. 서로 다른 창의 동일 단축키가 두 번 실행되지 않게 소비 소유자를 정한다.

### P18-S12 — 데이터·이미지 보관 설정

Data 위치, Data 가져오기 폴더 선택, 이미지 최대 용량 500MB~10GB(기본 5GB), 오래된 원본 백업 후 최대 100kB 썸네일 남기기, 1/2/3년 경과 자동 썸네일, 썸네일 전환 원본 일괄 삭제 UI를 제공한다. 썸네일만 남은 항목은 갤러리 흔적과 원본/백업 식별 정보를 유지한다.

이번 UI 단계는 위치 선택·정책 미리보기·대상/용량 안내까지다. 실제 파일 이동·삭제·복원은 후속이며 확인 버튼을 눌러도 성공 완료로 꾸미지 않는다. 제품 단계에서는 백업 검증 완료 → 썸네일 확정 → 참조 갱신 → 원본 정리 순서와 중단 복구를 따른다. 폴더 선택만으로 다른 위치 데이터를 덮어쓰지 않는다.

### P18-S13 — 캘린더 기준과 빠른 생성

이전/다음 월과 오늘 이동, 작성일/일정/알람 표시 기준을 제공한다. 작성일은 생성시각의 날짜, 일정은 일정이 지정된 메모/발생, 알람은 알람 설정 메모를 해당 알람 날짜에 투영한다. **작성일 기준 달력의 드래그가 생성시각을 변경해서는 안 된다.** 일정 드래그는 일정 기준에서 수행하고 다른 기준에서는 일정 지정 동작임을 분명히 하거나 비활성 처리한다.

날짜 셀 우측 상단에 포인터를 올리면 +가 보이고, 누르면 그 날짜가 일정인 새 스티커를 만든다. 날짜 셀 안 메모 제목 클릭은 해당 원본 스티커를 연다. 토요일 파랑, 일요일/검증된 한국 공휴일 빨강을 사용하되 날짜 숫자는 왼쪽 위의 작은 글자로, 메모는 제목 일부와 말줄임으로 읽을 수 있게 한다. 공휴일은 기존 오프라인 지원연도·출처 계약을 유지한다. 목록→일정 없는 메모 드래그·날짜 간 이동·기간/반복 범위 선택은 기존 요구를 유지한다.

### P18-S14 — 본문 입력 엔진

본문 탭과 댓글은 공통 편집 모델을 사용한다. 아래는 최종 편집 계약이며 이번에 실제 연결되지 않은 항목은 UI 미리보기/후속으로 명시한다. 단순 문자열에 서식 모양만 흉내 내고 구조화 편집 완료로 판정하지 않는다.

- 기호 `1.`, `1)`, `(1)`, `a.`, `A.`, `a)`, `(a)`, `A)`, `(A)`, `ㄱ.`, `ㄱ)`, `(ㄱ)`, `i.`, `i)`, `(i)`, `I.`, `I)`, `(I)`, `-`, `*`를 인식한다. 이전 12의 `가)` 등 기존 지원 기호도 유지한다. 새 계열이면 2칸 깊게, Enter는 **같은 단계 다음 번호**, Shift+Tab은 2칸 내어쓰기, 상위 계열 다음 번호 직접 입력은 해당 단계로 복귀한다. 알파벳 i/로마숫자 i는 기존 문맥과 연속번호로 구별한다.
- 표 오른쪽/아래 호버 +는 각각 열/행 추가. 현재 셀 우클릭은 행·열 추가/삭제, 선택 셀 범위는 열 너비/행 높이 균등화를 제공한다. PPT의 ‘행너비’는 행 높이 균등화로 해석한다. 표 안 텍스트에도 본문 서식을 적용한다.
- 이미지는 허용된 클립보드·파일 드롭으로 삽입한다. 25/50/75/100%/너비맞춤은 원본 비율 유지, 원본 가로세로비율 복원은 현재 너비를 유지한 높이 재계산이다. 너비맞춤은 현재 본문 가용 폭을 따르고 창 크기 변경에도 갱신한다. 문단 들여쓰기 안의 이미지도 그 문단 가용 폭을 따른다. PPT의 미완성 문구 ‘이미지 삽입시 들여쓰기가 된 구간’은 이 기본안으로 기록한다.
- #프로젝트 + Space, 인라인 [] + Space, ~~ / ~~~ 취소선은 S11과 같은 명령이다. IME 조합 이벤트를 소비하거나 자모를 쪼개지 않는다.
- URL 입력 뒤 Space/Enter, URL 붙여넣기는 링크로 변환한다. 이후 입력은 링크 범위 밖이다. 링크 우클릭 이름 변경, Ctrl+클릭 주소 복사를 제공한다. 자동 링크 변환이 외부 접속을 일으키지 않는다.
- 본문에 초점이 있을 때 Ctrl+휠은 텍스트·표·이미지를 30~200%로 확대/축소한다. 가운데 반투명 배율 표시가 잠시 보이고 조작 중단 후 사라진다. 우클릭 원본 비율 복귀는 100%다. 수집함 보드 확대와는 별도 상태이며 다른 창 배율을 바꾸지 않는다.

### P18-S15 — 전체메모·분류 폴더·휴지통

대표 메뉴를 전체메모로 바꾸고 상단에 폴더 보기/전체 메모보기 탭을 둔다. 기존 관계 보드·DAG 트리는 별도 탭/진입으로 보존하되 폴더를 메모 종속 관계로 해석하지 않는다. 나만의 위키 폴더와도 별도 분류다.

폴더 보기: 좌상단 폴더 트리, 좌하단 미배치 메모 목록, 우측 편집 가능한 선택 메모 미리보기. 선택 폴더가 없으면 루트, 선택 폴더가 있으면 하위에 새 폴더를 만든다. 동일 레벨 형제 생성은 선택 해제 또는 부모 선택으로 가능해야 한다. 폴더 이름 더블클릭은 이름 변경, 폴더 아이콘 클릭은 접기/펼치기다. 하나/여러 메모를 목록에서 폴더로 드래그하면 배치되고 미배치 목록에서 빠진다. 폴더 안 제목은 한 줄, 클릭은 우측 미리보기, 다른 폴더로 드래그하면 이동이다. 폴더 이동을 지원할 경우 자기/자손 드롭을 금지한다.

전체 메모보기: 상세 목록과 우측 편집 가능한 스티커 미리보기. 전체/프로젝트(프로젝트 없음 포함), 생성일/일정 정렬, 정기일정 제외/정기일정만, 위키만 필터를 제공한다. 정기일정 필터는 하나의 배타적 선택(전체/제외/정기만)으로 표현해 모순된 두 체크를 허용하지 않는다. 이 창의 빠른 검색은 목록/본문 일치 위치를 선택하고 이전/다음 찾기로 일치 위치를 이동한다. 탭이 여러 개면 대상 탭과 일치 개수를 안내하며 결과 선택 시 해당 탭과 커서를 연다.

편의기능에 휴지통 탭을 추가한다. 삭제 메모와 삭제 본문 탭은 유형을 구별해 상세 목록으로 표시한다. 복원은 같은 원본을 되살리며 중복 새 메모를 만들지 않는다. 원래 폴더가 없으면 미분류로 복원하고 안내한다. 탭의 원본 메모가 휴지통에 있으면 메모 복원이 선행되어야 한다. 영구삭제는 별도 확인, 보관기간 자동 삭제는 후속 실제 저장 단계다.

## 3. 공통 모델·아키텍처와 명령

UI 상태와 업무 원본을 분리한다. 현재 구현 자료구조가 다르더라도 다음 불변조건을 보장한다.

| 논리 모델 | 역할·불변조건 |
|---|---|
| Note | 안정 note_id, 제목·프로젝트·일정·알람·생성시각·완료는 탭 사이 공유 |
| NoteTab | tab_id, note_id, 제목, 본문, 순서, 숨김. 활성 탭 ID는 창별 UI 상태 |
| MemoWindow | window_id + note_id, 모드, 모드별 bounds, always_on_top, 색·투명도·active_tab_id. 다른 창의 인덱스에 의존하지 않음 |
| LockPreview | note_id별 잠금 화면 상태. 실제 암호/키 저장소나 보안 경계가 아님 |
| MemoFolder/Membership | 위키 폴더·DAG 부모와 독립. 메모 하나의 분류 위치를 이동하며 원본을 복제하지 않음 |
| TrashItem | note/tab 구분, original_id, 삭제시각, 원래 배치/소유자 정보; 복원/영구삭제 대상 |
| Settings | 일반/메인창/알람/스티커/단축키/데이터 설정. 실행 반영·미리보기·후속 상태 구분 |
| EditorSelection/SearchMatch | note_id + tab_id + 문서 위치. UTF-8 바이트 오프셋을 사용자 문자 위치로 오인하지 않음 |

새 탭/복제/삭제/복원/이동/일괄 바꾸기는 하나의 명령 경계로 처리한다. 선택·본문 초점·대화상자 대상은 안정 ID로 캡처한다. 리스트 정렬/필터/삭제 후 이전 인덱스가 다른 메모를 가리키지 않는다. egui 위젯·팝업 ID는 viewport/window_id/note_id/tab_id를 포함해 창별 상태 충돌을 막는다. 현재 활성 탭을 바꾸어도 다른 창의 키보드 초점·선택영역이 옮겨가지 않는다.

잠금 화면 전환은 앱 안의 노출 투영을 일관되게 가리되 실제 암호화가 없는 한 안전한 저장·보호라고 부르지 않는다. 잠금 비밀번호 입력을 로그·스크린샷 증거에 남기지 않는다. PDF/PPT/Excel 보안 락 우회·내용 추출은 이번 확장에도 허용하지 않는다.

## 4. 이전·후속 구현과 개발 순서

1. 기존 코드·화면·빌드·원본 모델을 조사하고 v1.7 회귀 기준을 확보한다. 새 UI가 최종 기술 스택 결정을 대체하지 않는다.
2. 창 상태/제목 추출/공통 설정 경계를 변경하고 여러 창·한글 입력을 먼저 검증한다.
3. 본문 탭, 더보기·잠금 시뮬레이션, 상세 목록·우측 편집, 전체메모 폴더와 휴지통을 연결한다.
4. 설정·단축키·캘린더 표시 기준·본문 도구를 연결한다. 실제 동작/미리보기/미연결을 화면과 문서에 맞춘다.
5. 아래 M22 시험과 슬라이드 추적표에 증거를 연결한다. 빌드 성공만으로 시각·IME·다중 창 수용을 통과하지 않는다.
6. 후속 제품 단계에서 영속 저장→암호화 설계/키 복구→백업/복원→실제 알림/상주/OS설정→대규모 리치 본문을 기존 01/06/07과 통합한다. UI 잠금과 실제 보호의 요구·검증은 별도로 둔다.

기존 단일 body는 첫 탭 하나로 감싸고 기존 제목·일정·완료·생성시각·메모 ID를 보존한다. 기존 창의 스티커 선호는 새 접기 정책으로 매핑하며 본문을 복제하지 않는다. 새 전체메모 폴더는 기존 위키 폴더와 독립적으로 시작한다. 기존 삭제 표시가 있다면 유형 있는 TrashItem으로 이관하고 자동 영구삭제를 첫 시작에 실행하지 않는다. 이번 메모리 프로토타입의 종료 초기화는 실제 스키마 이전 완료를 의미하지 않는다.

## 6. 검증 등록

`M22-T-01`~`M22-T-15`는 슬라이드 번호와 대응한다. 구체 절차·교차 회귀는 [08 테스트·인수](08-tests-acceptance.md)의 v1.8 절을 따른다. 각 요구의 구현/시험 결과는 [슬라이드 추적표](../docs/ppt-requirements-v18.md)에 별도로 기록한다. 현재 초기 상태는 모두 **검증 대기**이며, 실제 파일/OS 동작을 후속 범위에서 검증하기 전 제품 완료로 승격하지 않는다.
