## 데이터 모델·명령

프로젝트는 이름이 ID가 아니다. `Project(id,name,visibility,deleted_at)`이며 보이는 목록을 필터해도 ID가 바뀌지 않는다. UI 배열 인덱스를 영속 ID로 사용하지 않는다. 이름만 삭제는 `Note.project_id=null`로 같은 트랜잭션에 반영한다. 메모 포함 삭제는 메모/관계/첨부/댓글 영향 범위를 미리 표시하고 삭제·휴지통/복구 정책과 통합한다. 위키 포함 여부도 삭제 미리보기에 나타내며 숨김과 삭제를 혼동하지 않는다.

`ProjectVisibility` Active↔Hidden, Active/Hidden→DeleteScopePending→Deleted 또는 취소. Hidden→Active 시 기존 관계·폴더·완료·생성시간을 유지한다. 숨긴 프로젝트 포함 검색은 명시적 예외 조회이며 전역 숨김 해제가 아니다. 삭제 항목은 이 옵션으로 복원하지 않는다. 메모 간 관련 선의 반대쪽이 숨겨졌다면 제목/내용을 유출하지 않고 보이는 자식이 누락되지 않게 한다.

첫 줄 파싱은 입력 이벤트의 Enter 확정 시점에 한 번만 실행한다. IME Enter와 줄바꿈을 구별한다. `#프로젝트명`은 명령 줄로 소비하고 다음 줄을 제목/본문 입력으로 이어간다. 이름 앞뒤 공백·중복·대소문자/한글 정규화 정책을 기존 데이터 조사 후 고정한다. 숨긴 같은 이름은 새 ID를 무조건 만들지 말고 재활성화/기존 숨김 유지 선택을 표시한다. 프로토타입은 기존 이름을 재사용하므로 이 경우 메모가 숨겨질 수 있음을 알린다.

`created_at`은 저장 가능한 표준 시간(UTC+표시 시간대), UI는 로컬 날짜 범위를 UTC 반열림 범위로 변환해 질의한다. 생성일 기본은 실제 기록한 날이며 마이그레이션에서 알 수 없는 과거 시각을 현재 시각으로 지어내지 않는다. `SearchSpec(text,created_range?,schedule_range?,project_id?,has_image?,has_table?,has_link?,include_hidden,sort_basis)`는 모든 활성 조건을 AND 결합한다. 범위 시작>끝은 조회 전 오류로 표시. 첨부 조건은 현재 원본 참조/표/링크 색인 기준이며 예시 ID 나머지 연산 등 가짜 조건을 제품 로직에 쓰지 않는다.

날짜 클릭은 선택한 기준을 따른다. 생성시간 기준이면 생성일, 일정 기준이면 유효 일정일. 일정 없는 메모는 생성일 이동 대체를 명시하거나 별도 버튼을 제공한다. 우측 달력은 검색 결과만으로 축소하지 않고 그 날짜 주변의 접근 가능한 메모를 보여준다. 숨긴 결과 날짜를 눌러도 숨긴 프로젝트를 캘린더 전체에 노출하지 않는다. 검색/드래그/완료는 같은 원본 명령을 호출한다.

## 마이그레이션

기존 프로젝트 문자열은 안정 ID로 매핑, deleted/hidden 기본 false. 기존 생성시각이 있으면 그대로 이전하고 없으면 unknown+출처를 기록한다. 위키/일지/자산/검색 색인의 프로젝트 참조를 함께 검사한다. 숨김은 보안 접근 제어를 대체하지 않으며 사내 정책·권한을 우회하지 않는다.

## 시험

- M19-T-01: 프로젝트 이름만 삭제 후 메모/본문/댓글/부모 관계 보존, 포함 삭제는 해당 프로젝트 항목만 영향.
- M19-T-02: 숨김→모든 화면 제외→명시 검색 예외 포함→재활성화 전체 복원. 외부 열린 메모 창의 숨김 정책도 일치시킨다.
- M19-T-03: 새 `#이름` Enter, 같은 이름 두 번, 빈 이름, 숨긴 이름, 한국어 IME Enter, 본문 중간 # 문자는 비명령.
- M19-T-04: 생성일·일정 하루/기간·프로젝트·첨부 조건 조합, 제목/본문 각각 일치, 날짜 역전 오류.
- M19-T-05: 오래된 검색 결과 날짜 클릭→정확한 연/월 이동→주변 날짜 메모 검토. 검색어와 결과 원본은 유지.
- M19-T-06: 날짜 드래그·내용 편집·완료 후 created_at 불변, 같은 생성시각 항목의 안정 정렬.

예상 버그: 프로젝트 삭제 시 인덱스 이동으로 다른 메모의 프로젝트가 바뀜, 숨김을 목록에만 적용, 검색에 제목만 사용, 생성시간을 수정시간으로 덮어씀, 상세 조건의 빈 값/날짜 역전 처리 누락, 검색 결과 달력에 결과만 표시해 주변 작업이 안 보임. 안정 ID·공통 가시성 투영·불변 생성시각·SearchSpec 검증으로 방지한다.
