# 23. 프로젝트 단일 분류와 아이콘 도구

2026-11-10 최신 사용자 지시. 이 문서는 10/15/21/22의 라벨 및 도움말 배치 계약보다 우선한다.

## 분류 모델

- 메모의 분류는 사용자 프로젝트와 `프로젝트 없음`만 사용한다.
- `개인 / 프로젝트 / 회의` 고정 분류와 라벨 생성·할당·정렬·필터·대표 라벨 색띠를 폐기한다. `LABEL-01~08`과 해당 라벨 전용 인수시험은 적용 대상에서 제외한다.
- `Note.label`, 라벨 상수와 필터 상태, 편집창 라벨 선택, 보드 라벨 필터, 카드·목록의 라벨 이름/라벨 기반 색상 코드를 제거한다.
- 메모 자체의 색상은 스티커·최소화 상자·카드 꾸미기 설정으로 유지한다. 색상에 분류 의미를 자동 부여하지 않는다.
- 프로젝트 이름에 ‘개인’이나 ‘회의’가 포함되거나 메모 제목에 해당 단어가 있더라도 일반 사용자 데이터로 보존한다.
- 위키 폴더와 전체메모 정리 폴더, 메모 관계는 프로젝트와 별개인 기존 정리 기능이다. 이 변경으로 폴더를 프로젝트로 바꾸거나 메모를 삭제하지 않는다.
- 향후 영속 데이터 이전 시 기존 프로젝트 ID를 그대로 유지하고 라벨 필드만 버린다. 과거 라벨에서 새 프로젝트를 임의 생성하지 않는다.

## 아이콘 도구와 도움말

- 스티커 본문 도구는 글꼴, 글자 크기, 굵게, 기울임, 밑줄, 취소선, 표, 이미지, 투명도, 배율의 작은 아이콘으로 표시한다.
- 글꼴명, 글자 크기 값, `표 +`, `이미지 +`, `투명도`, `100%` 같은 긴 텍스트 컨트롤을 상시 줄에 두지 않는다. 아이콘을 누르면 작은 선택창을 열고, 굵게 등 켜기/끄기 동작은 즉시 반영한다.
- 작은 창에서 한 줄을 우선하고 폭이 부족하면 도구만 필요한 만큼 줄을 바꾼다. 본문 영역은 실제 도구 높이만큼만 예약한다. 탭과 추가 버튼은 항상 접근 가능해야 한다.
- 아이콘에는 명확한 툴팁, 접근성 이름, 선택 상태와 키보드 초점 표시를 제공한다. 팝업 내부에는 선택을 돕는 텍스트를 사용할 수 있다.
- 스티커 상단의 별도 물음표 도움말은 제거한다. 도움말 진입점은 더보기 메뉴에 둔다. 전체 편집창의 도움말도 더보기 메뉴로 제공한다. 메인 작업 공간 도움말은 별개다.

## 수용기준

| 시험 | 기대 |
|---|---|
| M23-T-01 | 편집·작업실·오늘/다음·전체메모·관계 보드에 고정 분류 및 라벨 선택/필터/이름이 없다. 프로젝트 없음과 프로젝트 선택은 동작한다 |
| M23-T-02 | 모델과 UI에 라벨 필드/상수가 없고 메모 자체 색상과 기존 프로젝트/폴더/관계/본문은 유지된다 |
| M23-T-03 | 360px 스티커의 서식 줄이 아이콘으로만 구성되고 긴 값은 선택창에서 표시된다. 본문 공간이 늘고 탭을 가리지 않는다 |
| M23-T-04 | 팝업 열기·선택·취소, 서식 토글, 툴팁·초점·접근성 이름, 작은 폭에서 줄바꿈을 확인한다 |
| M23-T-05 | 상단 물음표 버튼이 없고 더보기에서 오프라인 도움말을 열 수 있다. 닫기·접기·새 스티커·압정·완료는 유지된다 |

버그 위험은 숨겨진 라벨 필터가 빈 결과를 만드는 경우, 색상 설정을 라벨과 함께 삭제하는 경우, 프로젝트 이름을 고정 분류로 오인해 지우는 경우, 아이콘 변경 후 도구 높이를 과다 예약하거나 팝업이 편집 커서를 잃게 하는 경우다. 모델 제거, 실제 렌더링 높이 시험과 창 동작 회귀로 확인한다.
