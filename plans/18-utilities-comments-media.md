# 18. 편의기능 탭·일지 댓글·표/이미지 보관·즐겨찾기

> 최신 범위: [23 프로젝트 단일 분류·아이콘 도구](23-projects-icon-toolbar.md)에 따라 라벨과 `LABEL-*` 계약은 폐기되었다. 이 문서의 라벨 모델·필터·시험은 과거 설계 참조이며 구현하지 않는다. 프로젝트와 메모 자체 색상, 위키/정리 폴더는 유지한다.

v1.5 · 2026-11-09. 왼쪽의 업무일지·표·이미지·링크 메뉴는 `편의기능` 하나로 통합하고 중앙 탭으로 구분한다. 탭을 바꿔도 날짜 필터·검색어·댓글 펼침 상태를 유지한다.

## 데이터와 처리 경계

`JournalComment(id, completion_id, body, created_at)`는 위키 댓글과 다른 테이블. 비반복 완료는 note_id+완료 식별자, 반복 일정은 occurrence_id에 연결한다. 완료 해제/재완료 때 과거 댓글을 덮거나 새 회차에 잘못 재사용하지 않는다. 현재 프로토타입은 메모별 일지 댓글이며 제품에서는 완료 사건/회차 ID로 확장한다.

`AssetLocation(asset_id,path,last_verified_at,content_hash,byte_size,availability)`와 본문 참조를 구분한다. 외부 보관 후 본문 데이터를 비우더라도 메타데이터·원본 위치/해시/메모 참조는 유지한다. `AssetPresence`는 Embedded → ExportedVerified → ExternalOnly → TemporarilyLoaded → ExternalOnly. 내보내기 실패·내용 불일치·권한 없음은 Embedded 유지. 임시 캐시는 닫기/종료 시 해제하며 영속 자산 용량과 구분해 표시한다. 임시 파일을 다시 첨부하는 명령은 별도다.

갤러리는 원본 이미지의 파일 바이트 합계와 디코딩 메모리/GPU 사용량을 혼동하지 않는다. 기준은 상단에 명시한다. 실제 용량 제한 값은 사내 정책 조사 후 확정한다. 미리보기의 입력 제한(64 MB, 8192×8192, 디코딩 256 MB)은 개발 중 안전 한계이며 제품 요구의 확정 수치가 아니다.

출력은 사용자가 지정한 파일/폴더만 쓴다. 단일 저장은 기존 파일 덮어쓰기 확인을 제공하고, 일괄 저장은 자동 덮어쓰기하지 않는다. 작업 중단/실패 시 성공한 파일과 실패 파일을 구분한다. 경로가 바뀌거나 파일이 없어졌다면 경로 재지정으로 복구하되 이미지 ID/참조는 유지한다. 외부 보관 경로·해시도 백업에 포함하고 종료 후 기억하려면 영속 저장 모듈이 필요하다.

HTML 반입은 문서 텍스트만 파싱하고 스크립트/외부 이미지/스타일/추적 주소를 실행하거나 가져오지 않는다. 허용 프로토콜은 06/10 정책과 일치시킨다. 폴더 보존·가져오기 미리보기·대량 중복 처리는 10의 제품 계약 유지. 현재 UI 프로토타입은 UTF-8 링크 목록 반입만 제공한다. 보안 락이 걸린 PDF/PPT/Excel 원본을 읽거나 잠금을 우회하지 않는다.

## 테스트와 예상 결함

- M18-T-01: 완료 항목 두 개에 서로 다른 댓글, 개별/전체 토글 반복. 위키 댓글·일반 메모 수·검색 본문 불변.
- M18-T-02: 한국어·이모지·빈 셀·큰 표·병합 표 검색/HTML/TSV/이미지 복사, 클립보드 보안 차단 시 오류/원본 유지.
- M18-T-03: 일/월 경계의 이미지 날짜 필터, 전체/필터 용량 구분, 임시 이미지 용량 별도.
- M18-T-04: 이미지 내보내기→외부 파일 삭제/변조→본문 비우기 시도: 비우기 거부, 원본 유지.
- M18-T-05: 검증 후 비우기→기억 경로 임시 열기→닫기, 원본 메모 수·본문 용량과 임시 캐시 구분.
- M18-T-06: 일괄 출력 파일명 충돌·권한·디스크 부족·네트워크 드라이브 연결 끊김, 성공/실패 목록과 재시도.
- M18-T-07: HTML 악성 script/javascript/file/data URL·깨진 UTF-8·거대 파일·중복 URL, 실행/외부 요청 없이 안전 거부/건너뛰기.

예상 버그: 댓글 펼치기가 삭제로 연결됨, 반복 회차 댓글 혼합, 화면에 보이는 일부 셀만 복사, 썸네일 용량을 원본 용량으로 표시, 일괄 출력이 기존 파일을 덮음, 경로만 확인하고 다른 이미지 파일인데 원본을 비움, 임시 로딩이 자동 재첨부되어 용량 제한을 우회함. 전용 엔터티·검증 상태·출력 manifest·캐시 수명으로 방지한다.

## 단계

조회 UI/예시 표·갤러리 → 허용 클립보드/파일 대화상자 연결 → 자산 ID·해시·영속 카탈로그 연결 → 실제 본문 표/이미지의 모아보기 색인 → 대용량·보안 PC 시험. 프로토타입의 예시 데이터 복사 성공을 본문 에디터의 첨부/표 엔진 구현 완료로 간주하지 않는다.
